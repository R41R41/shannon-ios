Shannon Build 40

端まで続くTalk、全高ドロワー、ライト／ダーク対応のデフォルトアイコンを実機で確認します。

Shannon Internalへ配信済み

目的

TestFlightから既存のShannonを上書き更新し、会話・接続を保ったまま今回の画面改善が正しく動くことを確認します。

1. Build 40へ更新

  1. iPhoneでTestFlightを開きます。
  2. Shannonを開き、アップデートを押します。
  3. 表示されるバージョンが 0.1.0 (40) になったことを確認して、Shannonを起動します。

Shannonは削除しないでください。削除すると端末内キャッシュや接続情報へ影響する可能性があります。

2. 保持されるものを確認

  • 既存のトーク一覧と会話履歴が残っている
  • シャノンへ接続した状態が維持されている
  • 既存トークを開き、通常どおり会話できる

3. Talk画面を確認

  • 中央のトークタイトルと帯状のヘッダー背景がない
  • 左のサイドバー、右の新規トークが丸いボタンになっている
  • スクロールすると会話が時刻・ノッチの背後まで続いて見える
  • 上端のグラデーションで時刻や電波表示を読み取れる
  • 下端でも会話が入力欄の背後まで続き、文字はグラデーションで読める

4. サイドバーを確認

  1. 左上の丸いボタンからサイドバーを開きます。
  2. 背景が画面最上部から最下部まで届いていることを確認します。
  3. Shannonの見出しはノッチと重ならず、下部の設定まで完全に見えることを確認します。

5. アプリアイコンを確認

  1. 設定 → アプリアイコン → 自分で選ぶを開きます。
  2. デフォルトとシャノンの表情アイコンだけが表示され、比較用10案がないことを確認します。
  3. デフォルトを選びます。
  4. iPhoneのホーム画面アイコンをライト表示にすると白地版、ダーク表示にすると青地版へ変わることを確認します。

ホーム画面側のライト／ダーク設定に追従するため、アプリ内だけの配色変更とは切り分けて確認してください。

成功の目安

上の確認項目がすべて通り、会話履歴と接続が維持されていればBuild 40の配布・実機Smokeは完了です。

うまくいかない場合

  • TestFlightに更新が出ない：5〜15分待ち、画面を下へ引いて再読込します。
  • アイコンがすぐ変わらない：いったんホーム画面へ戻ります。それでも変わらなければShannonを再起動し、もう一度デフォルトを選びます。
  • 表示が崩れる：Shannonを終了して再起動します。アプリの削除はしません。
  • 履歴や接続が消えた：新規設定を進めず、その画面の状態を知らせてください。
