# 画面の構成（決定）

2026-10-03、所有者が比較ページ（Syzygy `work/shannon-unified-structure-comparison/index.html`）で選んだ結果。iOS・macOS・Windows の 3 つとも、この構成に従う。前の版（案の一覧）は、末尾の「検討した案」に短く残した。

選ばれたもの:

| 項目 | 選んだ案 | 比較ページのおすすめとの違い |
|---|---|---|
| 全体の構成 | B: トーク／作業／シャノン／設定 | 同じ |
| iPhone の入口 | A: いまのまま（左上のボタンとシート） | 同じ |
| 広い画面の並べ方 | A: トークの一覧はサイドバーの中 | 同じ |
| からだの置き場所 | B: トークの見え方の 1 つ | **違う**（おすすめは「からだ」という場所） |
| 運用の置き場所 | B: 設定の近く（「管理」） | **違う**（おすすめは「ようす」の中）。2 日前に iPhone の比較で選んだ形（ようすの中。`codex/shannon/ios-yousu`）を、この決定が置き換える |
| 色の意味 | A: iPhone の役割分けを 3 つとも | 同じ |
| 広い画面の文字 | B: 本文 15 | 同じ |

## 1. 入口は 4 つ

**トーク／作業／シャノン／設定。**

| 入口 | 中にあるもの |
|---|---|
| **トーク** | トークの一覧（シャノンから／トーク）、会話、音声会話、**シャノンの姿**（表示の 1 つ） |
| **作業** | 作業の一覧（いま／これから／終了）、作業の現在地、許可。広い画面では、開発と配信もここ |
| **シャノン** | 先頭にシャノンのいまと待っていること。その下に、ようす／頭の中／自律活動／書斎 |
| **設定** | 管理（運用、接続中の端末）、すがた、カメラ、イヤホンと話しかけ、声、予定、外観、接続、情報源 |

いつも見える所に置くもの（どの画面にいても分かる）:

- **あなたの対応を待っているものの数**（許可待ちの作業、シャノンからの話、感想待ち）。
- **カメラの状態**（切／見てよい）。
- **運用の印**（不調・報告が届かない・操作が失敗、のときだけ）。

## 2. iPhone の幅と広い画面での見せ方

そろえるのは、入口・中身・言葉・色。並べ方は、画面の広さに合わせる（iPhone の画面を引き伸ばして広い画面にはしない。`docs/DESIGN.md`）。

### 入口

| | iPhone | 広い画面（Mac・Windows） |
|---|---|---|
| 主の画面 | トーク | サイドバー + 本文 + 補助パネル |
| 入口の形 | 左上のボタンで開くシート。上にタイル 3 つ（作業／シャノン／設定）、その下にトークの一覧（シャノンから／トーク）と検索 | サイドバーの上に トーク／作業／シャノン、その下にトークの一覧と検索、いちばん下に 設定 |
| 待っている数 | 左上のボタンに赤い点。シートの 作業・シャノン のタイルに数 | サイドバーの 作業・シャノン の行に数 |
| カメラの状態 | 向き合う表示と音声会話の上に小さく出す。切の間は、設定のタイルの下の行に「カメラ: 切」 | サイドバーの下に「カメラ: 切／見てよい」。押すと 設定 › カメラ |
| 運用の印 | 左上のボタンに橙の三角（赤い点とは別の形）。シートの 設定 のタイルに同じ印 | サイドバーの 設定 の行に橙の三角。サイドバーの下に 1 行（例: 「運用: 報告が届いていません」）。押すと 設定 › 管理 › 運用 |

iPhone のシートは、いまの形（タイルとトークの一覧）のまま、タイルの中身だけが変わる（いま 作業／頭の中／設定 → 作業／シャノン／設定）。

### 場所ごと

| 場所 | iPhone | 広い画面 | デスクトップの追加 |
|---|---|---|---|
| **トーク** | 会話が 1 列。上の表示の切り替えで、一覧と「向き合う表示」（姿と話す）を替える。入力欄は下 | 会話が中央。姿を出すときは会話の横に立つ。右に補助パネル | 会話の目次、横の「現在地」、文書の保存、キーボードの近道 |
| トークの一覧 | シートの中 | サイドバーの中（入口の下） | — |
| 音声会話 | 入力欄から始める。通話の画面は姿と向き合う | 入力欄から始める。姿は会話の横 | — |
| **作業** | 一覧 → 押すと作業の現在地へ進む | 一覧と現在地を横に並べる | 開発の作業場（ファイル、差分、Git、ビルド）、配信（TestFlight） |
| **シャノン** | 1 列。先頭にシャノンのいま（顔、気分、待っていること）。下に 4 つの行。押すと奥へ進む | サイドバーで シャノン を選ぶと、2 列目に ようす／頭の中／自律活動／書斎、右に中身 | — |
| シャノン › ようす | シャノンのいま（気分、残っている気持ち、自分の時間にしていること、体のようす、最近のできごと） | 同じ中身を 2 列で | — |
| シャノン › 頭の中 | いまの入口（記憶、約束、人、目的、日記、使用量）。押すと奥へ | 一覧と詳しい内容を横に | — |
| シャノン › 自律活動 | 動いてよい状態と止めるスイッチ、今日の予算、シャノンからの提案、やりたいこと、使うモデル、したことの記録 | 同じ中身を 1 画面に（Windows のいまの形） | — |
| シャノン › 書斎 | 一覧 → 押すと作品へ | 一覧と作品を横に | — |
| **設定** | シート。先頭に 管理 | 画面の 1 つ（Mac は ⌘, でも開く）。左に区画、右に中身 | 専用フォルダ、起動時に開く、使うカメラの選択と映るものの確認、トレイ（メニューバー） |
| 設定 › 管理 | 運用、接続中の端末 の 2 行。押すと奥へ | 運用と接続中の端末を並べる | — |
| 設定 › すがた | 姿、映し方、体に起きたことを伝える、触れたときの返事 | 同じ。加えてデスクトップに立つ体 | デスクトップに立つ体（出す・隠す、常に手前、大きさ）、配信用の出力（OBS）、表情としぐさの確認 |
| 確認 | 下からの確認のシート。長く効く許可と運用の操作は長押し | 確認のダイアログ（同じ文）。長く効く許可と運用の操作は、ポインターで押し続ける | — |

iPhone だけのもの（シャノンからの電話、アプリを閉じても待機する、通話中の場所）は、設定と音声会話の中に置く。デスクトップには出さない。

## 3. からだは、トークの表示の 1 つ

「からだ」という場所は作らない。シャノンの姿は、話す場所に出る。

**どこに何を置くか**

| もの | 置き場所 |
|---|---|
| 姿そのもの | トークの「向き合う表示」（iPhone）／会話の横（広い画面）。音声会話でも同じ姿 |
| 姿の切り替え（水の光の目／Live2Dの姿） | トークの表示の設定（表示の切り替えボタンから開くメニュー）と、設定 › すがた。同じ設定で、端末ごとに覚える |
| 映し方（全身／上半身）、位置を戻す | トークの表示の設定（Live2Dの姿のときだけ出る）と、設定 › すがた。大きさと位置は、姿の上で 2 本の指（広い画面はスクロールとドラッグ） |
| 体に起きたことをシャノンに伝える | 設定 › すがた（入切は設定にだけ置く。話している最中に間違えて切り替えないため） |
| 触れたときの返事（文字で返す／声で返す） | 設定 › すがた |
| 触る（撫でる・つつく・くすぐる・手をつなぐ） | トークの向き合う表示の中の姿に、そのまま触れる |
| デスクトップに立つ体の入切、常に手前、大きさ、配信用の出力 | 設定 › すがた と、トレイ（メニューバー）のメニュー。体そのものは、アプリの窓の外 |
| 読み込みの時間・コマ数などの確認 | 設定 › 診断 |

**iPhone の幅**: いまある「向き合う表示」（`ShannonConversationView+Dialogue.swift`）が、そのまま姿の居場所になる。上に姿、下にシャノンの直前のひとことと入力欄。入力欄をたたむと、姿が画面いっぱいになる（触るために開く場所が無くなる、という代わりの払いを、これで小さくする）。水の光の目のときは、いまの見た目のまま。

**広い画面**: 表示の切り替えを入にすると、会話の右に姿の列が立つ（会話は読みやすい幅のまま中央）。姿の列は、目次・現在地と同じ補助パネルの場所を使う（3 つめの種類「すがた」）。切のときは、いまと同じ会話だけの画面。

**`codex/shannon/two-forms` で作っている別の「からだ」の画面**: たたんで、トークの表示に入れる。

| ブランチにあるもの | 行き先 |
|---|---|
| 「からだ」の画面の舞台（Live2D の姿、触る、2 本の指） | トークの向き合う表示の舞台（ブランチでは、ここの姿は触れず、押すと「からだ」の画面が開く。これを、その場で触れるようにする） |
| 画面の中の、姿の切り替え・映し方・位置を戻す | トークの表示の設定と、設定 › すがた |
| 画面の中の、体に起きたことを伝える・触れたときの返事 | 設定 › すがた |
| 「いま: 〈表情〉・〈していること〉」の行 | 向き合う表示の姿の下（すでに近いものがある）と、シャノン › ようす |
| トークのツールバーの「からだ」のボタン（`figure.stand`） | 無くす。表示の切り替えボタン（一覧 ⇄ 向き合う）が、その役目 |
| 設定の「からだを開く」（iPhone は全画面、Mac はシート） | 無くす。設定 › すがた には「トークで姿を見る」を置き、押すとトークの向き合う表示（Mac は会話の横）が開く |
| 体のページ（embed）、表情・気分・口の動き、触れたことを送る仕組み | そのまま使う |

**Windows**: いまは体の窓が「姿と話す」場所で、管理画面のトークには姿が無い。決定に合わせて、管理画面のトークの横にも同じ姿（同じ体のページ）を出せるようにする。体の窓は「デスクトップに立つ体」としてそのまま残る（デスクトップの追加）。

## 4. 運用は、設定 › 管理

「ようす」は、シャノンのことだけにする（シャノンのいま）。旧ランタイムのサービスの状態と操作は、設定の中の「管理」に置く。

- **場所**: 設定のいちばん上の区画「管理」。行は 2 つ: 運用（状態、Minebot の作業、予定、今日の数字、スキル、操作の記録、開始・停止・起動・今すぐ実行）、接続中の端末（一覧と解除）。設定の横に別の入口は作らない（入口は 4 つのまま）。
- **報告が 1 度も届いていない間**: 運用の行は「まだ報告が届いていません」と出す（行は消さない。Windows のいまの形は、入口そのものが出ない）。
- **止まっていることに気づけるように**（比較ページが挙げた代わりの払いへの手当て）:
  1. 印を出すのは、不調のサービスがある・報告が 3 分届かない・サーバーに届かない・操作が失敗か期限切れ、のとき。
  2. iPhone: 左上のボタンに橙の三角（未確認の赤い点とは別の形）。シートの 設定 のタイルに同じ印。設定 › 管理 › 運用 の行に、印と理由を 1 行（「YouTube が不調」など）。
  3. 広い画面: サイドバーの 設定 の行に橙の三角。サイドバーの下に 1 行。どちらも押すと 設定 › 管理 › 運用。
  4. 色だけに頼らない（三角の形と、言葉）。
- **置き換えるもの**: 2 日前に iPhone の比較で選んだ「ようすの中に運用」（`codex/shannon/ios-yousu` の、ようすの上の切り替えと、ようすのタイルの印）。ブランチの運用の画面・文言・確認の文は、そのまま使う。変わるのは入口と印の場所だけ。`shannon://yousu/ops` のリンクは、設定 › 管理 › 運用 を開くようにする。

## 5. 色・文字・承認・ことば

- **色**: iPhone の役割分けを 3 つとも（`design/tokens.json`）。押せるもの = 青、シャノンがいること = 藍、うまくいった・動いている = 緑、あなたの判断が要る = 橙、危ない = 赤。Mac は OS の強調色をやめる。Windows は 1 つの青を 4 つの役割に分ける。
- **文字**: iPhone は Dynamic Type のまま。Mac と Windows は本文 15、補足 12、行の高さ 40（`typography.desktop`、`size.desktopRowHeight`）。
- **承認**: 今回だけ許可／この作業中／許可しない の 3 つ。長く効く許可は長押し（0.6 秒）で決める。広い画面では、ポインターでボタンを押し続ける。キーボード・VoiceOver・スクリーンリーダーで決めるときは、同じ文の確認が出る。運用の操作も同じ。`docs/DESIGN.md` の「Mac は長押しなし」は、この決定で書き換えた。
- **ことば**: トーク／作業／提案／許可待ち／準備中／いま・これから・終了／音声会話／音声会話を開始・終了／友人も一緒／会話中にシャノンがカメラで見る／切・見てよい／考えている…／シャノンに話す／あなた／自律活動。`design/strings.ja.json` に入れた。直す場所は [`copy-differences.md`](copy-differences.md)。

## 6. まだ決まっていない小さなこと（所有者へ）

選んだ結果からは決めきれなかったもの。おすすめを添えた。おすすめのままでよければ、返事は要らない。

| # | 問い | おすすめ |
|---|---|---|
| 1 | 「シャノン」を開いた先頭のカード（顔・気分・待っていること）と「ようす」は、別のものか | **カードを押すと「ようす」が開く。** 行は 頭の中／自律活動／書斎 の 3 つにして、ようすの入口はカードが兼ねる（同じ中身への入口を 2 つ並べない） |

## 7. この決定で変わったもの

- `design/strings.ja.json`: 決まった言葉（`decided`）。
- `design/tokens.json`: 広い画面の文字（`typography.desktop`）、行の高さ、決定の記録。
- `docs/product/feature-matrix.json`: `structure.four-entries`、`structure.shannon-hub`、`tasks.hold-to-confirm`、`settings.figure`、`touch.reply-mode`、`settings.admin`、`ops.attention-mark` を足した。領域ごとに、決まった構成での場所（`place`）を書いた。
- `docs/DESIGN.md`: 長押しの文。
- 進める順番: [`roadmap.md`](roadmap.md)。Windows の担当へ: [`for-windows-app.md`](for-windows-app.md)。

実装が入るときに直すもの:

- `docs/design/screens/<platform>/*.yaml`（画面ごとの決まり）を、この構成に合わせる。
- `scripts/check-architecture.mjs` は、iPhone のトークが `NavigationStack` とシートを使うことを確かめている。入口の形はいまのままなので、変えなくてよい。

## 付録: 検討した案

- **全体の構成**: A = 7 つの入口を平らに（トーク／作業／ようす／自律活動・書斎／頭の中／からだ／設定）。どこも 1 回で開けるが、iPhone のシートが長い。**B = 3 つの柱と設定（選ばれた）。** C = 6 つの入口で、頭の中を「ようす」の中へ。
- **iPhone の入口**: **A = いまのシート（選ばれた）。** B = 下にタブ。1 回で移れるが、トークの画面が狭くなる。
- **広い画面**: **A = トークの一覧はサイドバーの中（選ばれた）。** B = トークを開いたときだけ 2 列目に一覧。
- **からだ**: A = 「からだ」という場所。体のことが 1 か所に集まる。**B = トークの見え方の 1 つ（選ばれた）。** 話すことと体が離れない。触るためだけの場所は無くなる。
- **運用**: A = ようすの中。止まっていることに気づきやすい。**B = 設定の近く「管理」（選ばれた）。** シャノンのようすと、サービスの管理が混ざらない。
- **色**: **A = iPhone の役割分けを 3 つとも（選ばれた）。** B = デスクトップは青 1 色のまま。
- **広い画面の文字**: A = 本文 17。**B = 本文 15（選ばれた）。** C = 本文 13。
- **承認**: **A = どこでも長押し（選ばれた）。** B = 広い画面は確認のダイアログ。
