# 画面の構成（案）

2026-10-03。**これは案で、決定ではない。** 所有者が、比較ページ（iPhone の幅と広い幅の絵）を見て選ぶ（ADR-0004 の進める順の 2）。この文書は、その比較ページを作るための材料。

いまの 3 つの入口の並びは [`gaps.md`](gaps.md) の 3 にある。

## 1. そろえるもの・そろえないもの

そろえるもの:

- **領域**（どんな場所があるか）と、その名前。
- 領域の中で、何が見られて、何が操作できるか。
- 言葉、色、余白（`design/strings.ja.json`、`design/tokens.json`）。

そろえないもの:

- 並べ方。iPhone は 1 列、広い画面はサイドバーと本文（と補助パネル）。iPhone の画面を引き伸ばして Mac や Windows の画面にはしない（`docs/DESIGN.md`）。
- OS の部品。iPhone と Mac は OS の一覧・シート・ツールバー、Windows は自前の HTML。

## 2. 領域の中身（どの案でも同じ）

出発点として渡された領域は、トーク／作業／ようす（シャノンのいま・運用）／自律活動・書斎／からだ／設定。これに、**いま iPhone と Mac にある「頭の中」（記憶・約束・人・目的）の置き場所が入っていない**。下の案は、その置き場所の違いでもある。

| 領域 | 見られるもの | 操作できるもの | デスクトップの追加 |
|---|---|---|---|
| **トーク** | トークの一覧（シャノンから／トーク）、履歴、返事の表情、出典、作った文書、「覚えました」の行、作業の知らせ | 送る、添付、Web で調べる、新しいトーク、検索、題名の変更、アーカイブ、声の会話を始める、声で入力 | 会話の目次、横の「現在地」、文書をファイルに保存、キーボードの近道 |
| **作業** | 一覧（いま／これから／終了）、目的・いま・次、計画、変更、検証 | 提案を始める・やめる、許可、追加の指示、一時停止・再開・中止、ピン留め、アーカイブ | 開発の作業場（ファイル、差分、Git、ビルド）、配信（TestFlight） |
| **ようす** | シャノンのいま（気分、残っている気持ち、自分の時間にしていること、体のようす、待っていること、最近のできごと）。運用（サービスの状態、Minebot の作業、予定、今日の数字、操作の記録） | 待っていることを開く。運用の開始・停止・起動・今すぐ実行（確認つき） | 広い画面では、いまと運用を横に並べる |
| **自律活動・書斎** | 動いてよい状態、今日の予算、シャノンからの提案、やりたいこと、使うモデル、したことの記録。書斎（物語、メモ、直した記録） | 止める・解除、予算のお願いへの返事、提案を始める・見送る、休ませる・やめるよう伝える、感想を返す、しまうよう伝える | 一覧と本文を横に並べる |
| **頭の中** | シャノンの気持ち・関心・関係、記憶、約束、人、続けている目的、日記、使用量 | 記憶を直す・忘れさせる・戻す、約束を完了にする、人の名前を直す・まとめる、目的を止める・完了にする | 一覧と詳しい内容を横に並べる |
| **からだ** | 二つの姿（水の光の目、Live2D の姿）、表情、しぐさ | 姿の切り替え、触る、映し方、大きさと位置 | デスクトップに立つ体（出す・隠す、常に手前、つまんで運ぶ、PC の様子への反応）、配信用の出力（OBS）、表情としぐさの確認 |
| **設定** | 接続、接続中の端末、外観、声、予定、カメラ、イヤホンと話しかけ、情報源、版 | それぞれの入切、接続の解除 | 専用フォルダ、起動時に開く、使うカメラの選択と映るものの確認、トレイ（メニューバー）のメニュー |

iPhone だけのもの（シャノンからの電話、アプリを閉じても待機する、通話中の場所）は、設定と声の会話の中に置く。デスクトップには出さない。

どの案でも、次の 2 つはいつも見える所に置く。

- **カメラの状態**（見られない／見てよい／いま見ています）。いまは Windows だけ。
- **持ち主の対応を待っているものの数**（許可待ちの作業、シャノンからの話、感想待ち）。

## 3. 案（3 つ）

### 案 A: 7 つの入口を平らに並べる

トーク／作業／ようす／自律活動・書斎／頭の中／からだ／設定

- **良くなること**: どの場所も 1 回で開ける。いまの Windows（6 つ）と iPhone（一覧のシート）に、いちばん近い。作り直しが少ない。
- **代わりに払うもの**: 入口が 7 つで、iPhone の一覧のシートが長くなる（トークの一覧が下へ押される）。「ようす」「頭の中」「自律活動」のどれにもシャノンのいまの状態が出るので、どこを見ればよいか迷う。
- iPhone: トークが主の画面。左上のボタンのシートに 6 つの入口と、トークの一覧。
- 広い画面: サイドバーの上に 7 つ、下にトークの一覧。

### 案 B: 3 つの柱（トーク・作業・シャノン）と設定

トーク／作業／シャノン（ようす・頭の中・自律活動・書斎・からだ をまとめた場所）／設定

- **良くなること**: iPhone で迷わない。「シャノンについてのこと」が 1 か所に集まり、いちばん上にシャノンのいま（顔・気分・待っていること）、その下に 頭の中／自律活動／書斎／運用／からだ の入口が並ぶ。入口が少ないので、iPhone でタブにもできる。
- **代わりに払うもの**: 運用とからだが 1 段深くなる（2 回押す）。Windows の作り直しがいちばん大きい（いま独立している自律活動・書斎・運用をまとめる）。「シャノン」の画面が長くなりやすい。
- iPhone: トークが主の画面。シートには 作業／シャノン／設定 とトークの一覧。「シャノン」は 1 列の一覧で、行を押すと奥へ進む。
- 広い画面: サイドバーに 4 つ。「シャノン」を開くと、左にその中の入口（ようす、頭の中…）、右に中身（サイドバー + 中の一覧 + 本文の 3 列）。

### 案 C: 出発点の 6 つ。頭の中は「ようす」に入れる

トーク／作業／ようす（いま・頭の中・運用）／自分の時間（自律活動・書斎）／からだ／設定

- **良くなること**: 渡された出発点にいちばん近い。「ようす」が、シャノンの状態を見る 1 つの場所になる（いま = 気分と体、頭の中 = 覚えていること、運用 = 外で動いているもの）。入口は 6 つで、いまの Windows と同じ数。
- **代わりに払うもの**: 「ようす」の中が 3 つに分かれて重くなる。記憶を直す・忘れさせるという操作が「ようす」（見る場所）の下に入るので、名前と中身が少しずれる。iPhone で「頭の中」を使い慣れた所から 1 段動く。
- iPhone: シートに 5 つの入口。「ようす」は上の切り替え（いま／頭の中／運用）。
- 広い画面: サイドバーに 6 つ。「ようす」は、いまと運用を横に並べ、頭の中は一覧と詳しい内容。

### 3 つの案の比べ方

| | 案 A | 案 B | 案 C |
|---|---|---|---|
| 入口の数 | 7 | 4 | 6 |
| iPhone のシートの長さ | 長い | 短い | 中くらい |
| 運用まで何回押すか | 1 | 2 | 1〜2（切り替え） |
| 頭の中まで | 1 | 2 | 2（切り替え） |
| いまの iPhone からの変化 | 小さい（入口が増える） | 中くらい（頭の中が「シャノン」の中へ） | 中くらい（頭の中が「ようす」の中へ） |
| いまの Windows からの変化 | 小さい（頭の中・ようす・からだが増える） | 大きい | 中くらい（自律活動と書斎をまとめる） |
| いまの Mac からの変化 | 中くらい（自律・ようす・からだの入口が増える） | 中くらい | 中くらい |

## 4. 案とは別に、決める所

どの案を選んでも、次は別に決められる。

**(1) iPhone の入口の形**

- ア: いまのまま。トークが主の画面で、左上のボタンのシートに入口とトークの一覧。良い所: トークの画面が広い。OS の部品のまま。払うもの: ほかの場所へ行くのに、いつも 2 回押す。
- イ: 下にタブ（案 B なら トーク／作業／シャノン）。良い所: 1 回で移れる。未確認の数がいつも見える。払うもの: トークの画面が、タブの分だけ狭くなる。入力欄とタブが下に重なる。入口が 5 つを超える案 A・C には向かない。

**(2) 広い画面で、トークの一覧をどこに置くか**

- ア: サイドバーの中（入口の下）。いまの Mac と Windows。良い所: どの場所にいても、トークへ 1 回で戻れる。払うもの: サイドバーが長い。
- イ: トークを開いたときだけ、2 列目に出す。良い所: サイドバーが入口だけになり、3 つの画面で同じ形になる。払うもの: ほかの場所から特定のトークへ行くのに 2 回押す。

**(3) からだを、領域にするか、トークの見え方にするか**

- ア: 領域にする（出発点の案）。姿の切り替え・触る・映し方が 1 か所に集まる。
- イ: トークの見え方の 1 つにする（いまの iPhone の「向き合って話す表示」の続き）。からだの設定は設定へ。良い所: 話すことと体が離れない。払うもの: 触るためだけに開く場所が無くなる。
- デスクトップに立つ体は、どちらでも「アプリの外の窓」として別にある。その入切は、からだ（ア）か設定（イ）に置く。

**(4) 運用を、ようすの中に置くか**

- ア: ようすの中（出発点の案。iPhone のブランチはこの形）。
- イ: 設定の近く（「管理」としてまとめる）。良い所: シャノンのようすと、旧ランタイムのサービスの状態は、別の話。払うもの: 止まっていることに気づきにくい。

## 5. 広い画面と iPhone で、同じ構成をどう見せるか

| | iPhone の幅 | 広い画面（Mac・Windows） |
|---|---|---|
| 入口 | シート（またはタブ）の一覧 | サイドバー |
| 一覧と中身 | 一覧を押すと、中身へ進む（戻るボタンで戻る） | 一覧と中身を横に並べる |
| 補助の情報 | 下からのシート、または次の画面 | 右の補助パネル（現在地、目次） |
| 確認 | 下からの確認のシート。取り消せない操作は長押し | 確認のダイアログ（同じ文） |
| 設定 | シート | 画面の 1 つ（Mac は ⌘, でも開く） |
| いつも見えるもの | 上の帯（作業の知らせ）、入口の印 | サイドバーの下（カメラ、接続）、入口の数字 |

デスクトップの追加は、領域を増やさず、同じ領域の中に付ける（2 の表の右の列）。例外は「デスクトップに立つ体」と「トレイ（メニューバー）」で、アプリの窓の外にある。トレイのメニューは、同じ領域への近道と、体の入切だけにする。

## 6. 比較ページを作るときに描くもの

- 3 つの案それぞれ、iPhone の幅と広い幅で、入口を開いた所と「シャノンのいま」を開いた所（6 枚）。
- 4 の (1) と (2) は、選ばれた案で、ア・イを並べる。
- 同じ色と文字（`design/generated/shannon-tokens.css`）、同じ言葉（`design/strings.ja.json`）で描く。言葉がまだ決まっていない所は、[`copy-differences.md`](copy-differences.md) の候補を並べて見せる。

## 7. 選んだあとに直すもの

- この文書を「決まった構成」に書き直す（案を消して、選ばれたものだけにする）。
- `docs/design/screens/<platform>/*.yaml` を、同じ構成に合わせて書き直す。
- `feature-matrix.json` の領域（`area`）を、選ばれた構成に合わせる。
- `scripts/check-architecture.mjs` は、iPhone のトークが `NavigationStack` とシートを使うことを確かめている。タブに変えるなら、その検証も一緒に変える。
