## 6. 分からなかったこと

一覧表で `unknown` にしたもの、または状態は書いたが確かめきれていないもの。

- `talk.feeling-strength` の Windows: サーバー側の変更（`codex/shannon/text-feeling-strength`）なので、Windows の返事の表情にも出るはずだが、ブランチが入ってから確かめる。
- `look.app-camera` の Mac: 設定と見る仕組みは共通のコードにある。Mac のトークに「いま見ました」の表示が出るかは、Mac のトークのコードからは見つからなかった（`partial` にした）。
- `body.form-switch` と `reach.body-speaking`（ブランチ `two-forms`）: Mac のトークに姿の切り替えが効くか、iPhone のからだの画面で場面ごとの一言まで出るかは、ブランチの文言から読んだだけ。
- iPhone のトークで、文字の返事を声で読み上げる設定は見つからなかった（`no` にした）。あるはずなら、場所を教えてほしい。
- 運用の画面の長い文 2 つ（予定の説明、操作の記録の下の説明）は、iPhone のブランチの側を前半までしか照合していない。
- Windows のコードは、`docs/windows-app-features.md`、`README.md` の一部、`docs/operations-console.md`、`src/desk/` の全画面、`src/bridge.ts`、スタイル、トレイのメニューを読んだ。体の演技（`src/acting/`）と声（`src/voice/`、`electron/voice.ts`）は、ファイルの名前と README の説明から書いた所がある。
- `shannon-desktop` の README には「Mac の実機ではまだ動かしていない」とある。ADR-0004 は「Mac には 2 つのアプリがある」としている。Mac の Electron 版がいま実際に使われているかは、確かめていない。
- 見た目は、値をコードから読んだだけで、画面を並べて見比べてはいない。

## 7. 進める順番の案（小さな一歩ずつ）

**この案は [`roadmap.md`](roadmap.md) に置き換えた。** 下は、所有者が選ぶ前に書いたもの。

ADR-0004 の順（仕様 → 所有者が構成を選ぶ → Apple をそろえる → Windows を直す → Mac の体）に沿って、1 つずつ入れられる大きさに分けた。

1. **言葉を決める（所有者）。** [`copy-differences.md`](copy-differences.md) の ◎ の 20 行ほどから。とくに、トーク／会話、提案／作業候補、許可待ち／判断待ち、友人も一緒／友人といっしょ、音声会話／声の会話。決まった言葉を `strings.ja.json` に入れる。
2. **画面の構成を選ぶ（所有者）。** [`information-architecture.md`](information-architecture.md) の案から、比較ページ（iPhone の幅と広い幅）を作って選ぶ。
3. **作業中のブランチを入れて、一覧表を直す。** `ios-yousu`、`two-forms`、`incoming-call`、`text-feeling-strength`。入ったら、その行を `yes` にして `evidence` を書く（検証が注意を出す）。
4. **iOS の色を、生成した値に向ける。** 値は同じなので、見た目は変わらない。続けて余白・角丸。
5. **Mac を共通の値にそろえる。** OS の強調色を `action` と `intelligence` に、角丸 10 と余白 10・14 を目盛りに。あわせて「会話」を決まった言葉に。画面ごとに 1 つずつ。
6. **運用の文言を、生成した文に向ける**（iPhone と Windows の両方）。もう同じ文なので、置き換えるだけ。続けて、作業の状態の語。
7. **Windows の色を生成した CSS に向ける。** `desk.css` の 12 個の変数を置き換える。青 1 色に持たせている 4 つの意味を、`action`・`intelligence`・`success`・`attention` に分ける。
8. **Windows の作業の言葉と、許可の出し方をそろえる。** 「続きが必要」を足す。
9. **Mac に足りないものを入れる。** 「この作業中は許可」、通知、ようす（いま・運用）の入口。
10. **Windows の入口を、選ばれた構成にする。** 頭の中（まず読むだけ）を足す。
11. **Windows のトークをそろえる。** 検索、題名の変更とアーカイブ、添付、コピーと送り直し、「覚えました」の行。
12. **Mac のデスクトップの体を SwiftUI で作る**（体のページを使う）。常に手前、大きさ、PC の様子への反応、配信の出力、専用フォルダの順に移す。移し終えたら、Mac の Electron 版をやめる。
13. **声の会話をそろえる。** Mac に入れる。Windows の管理画面からも始められるようにし、ミュートと「友人も一緒」の切り替えを入れる。無言で終わるまでの長さを 1 つに決める。
14. **設定をそろえる。** 3 つとも同じ見出しと順番にする。体の入切を iPhone からも見られるようにするには、サーバーに口が要る（`shannon-desktop` の `docs/windows-app-features.md` の 2）。
