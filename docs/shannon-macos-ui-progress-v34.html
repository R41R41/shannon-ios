会話UIの再調整

2026年9月7日時点。Mac版の最初のネイティブ画面を、便利さと可読性を優先するChatGPT型の構造へ寄せた。水色を面の色として使わず、Shannonの存在・状態・重要操作だけに残す方針。

ローカル保存済み・ここで一時停止

今回の到達点

会話面を最下部まで延長

入力欄を通常レイアウトから外し、会話のスクロール面に重ねる構造へ変更。最後の返答は入力欄の上まで安全にスクロールできる。

入力欄を前景へ

二重になっていたmaterial背景を一層へ整理。無彩色・薄い透過・弱い境界線と影で、内容より目立たない浮遊composerにした。

ダーク配色を無彩色化

タイトルバー、会話面、作業strip、composerに残っていた青みを抑えた。水色は感情の点や明示的な操作色に限定する。

サイドバーを平坦化

選択項目のカード背景を撤去し、太さと階層だけで現在地を示すリストへ変更。検索欄も囲いを外し、区切り線だけにした。
