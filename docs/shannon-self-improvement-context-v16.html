どこまでで完成か

コードだけでなく、試験・配備・実機・再接続までを判定する。

完了の判定

実装 → 回帰試験 → アプリbuild → 必要ならAzure → 必要なら実機

途中でアプリを離れても、タスク状態はAzureに残る。Agent Host再起動後は保存済みCodex threadへ復帰する。外部条件が足りない場合は、完了扱いにせず残作業を一つに特定する。
