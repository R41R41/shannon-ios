Macを実Shannonへ安全に接続する

目的は、Macへ端末固有・期限付きの接続資格を渡し、iPhoneと同じ会話、記憶、作業へ接続できることを確認することです。接続前のiPhone履歴やAzureの正本は削除・置換しません。

実行するタイミング

まだこちらから「実接続テストを始めます」と案内されていなければ、実行不要です。

署名済みMac Debug buildを用意し、他のApple署名・TestFlight作業が動いていない区切りで行います。

手順

  1. iPhoneのShannonを開き、設定内の接続端末管理から「新しい端末を接続」を選びます。
  2. 端末名へ「このMac」と入力し、接続リンクを1件だけ発行します。
  3. 発行された shannon://connect/... をAirDropなどの端末間共有でMacへ渡し、Macで開きます。リンクをチャット、Git、HTML、メモへ貼り付けないでください。
  4. Shannon Deskの左下が「接続済み・このMac」になったら、その行を開きます。
  5. 「接続を確認」を押し、「認証された通信」が「確認済み」になるまで待ちます。
  6. トーク一覧に既存履歴が出ることだけ確認し、結果をこちらへ「接続確認済み」と伝えます。テスト送信はこちらで手順を区切って実施します。

成功の見え方

  • 左下: 「接続済み・このMac」
  • 接続詳細: 「認証された通信・確認済み」
  • 既存トークのタイトルが表示される
  • iPhone側の会話履歴が変わらず残る

失敗した時の安全な戻し方

  • 通信失敗: Macのネット接続を確認し、「接続を確認」をもう一度だけ押します。
  • 401／無効: 古い資格は使わず、新しい接続リンクを1件だけ発行します。
  • リンクが別アプリで開く: 操作を止め、URLをどこにも貼らず「Macで開かなかった」と伝えてください。
  • 履歴が空: 新しい会話を作らず停止します。iPhoneの履歴は削除しないでください。

共有しないもの

接続URL、token、API key、証明書、秘密鍵、Keychainの内容、実会話本文はスクリーンショットや報告へ含めません。
