01 / Decision

UX改善へ入るのは「今」

v1.2を機能追加版ではなく、UX・Presence完成版にする。音声や情報源を先に増やすと、入力方法と画面状態がさらに増えて使いにくさの原因が分からなくなる。既存の主要機能が一通り揃い、遠隔配信も動いた現在が最も安全な区切り。
BEFORE

すでに揃った基盤

複数トーク、記憶、感情、日記、自発通知、Aether、Agent作業、TestFlight自動配信。

NOW

触り心地を統一

迷い、重なり、隠れた操作、視線移動、キーボードとスワイプの衝突をまとめて除く。

AFTER

音声を足す

固まった会話画面へ、マイク・聞き取り中・発話中・中断という新しい状態を安全に追加する。

03 / Scope

v1.2で直し切る範囲

トーク

返信の幅、表情アイコン、コピー、日付、過去話題カード、入力欄、送信・失敗・再試行を一貫させる。

トーク一覧

右スワイプの追従性、選択中表示、最終会話時刻、新規作成、タイトル編集を長押しに隠さない。

対話モード

画像が必ず見えること、吹き出しの位置、長文展開、考え中、キーボード表示時の縮小を実機で調整。

メモリー

「いま／知識／日記」の情報階層、編集後の反映、空状態、更新中、失敗時の戻り道を整える。

共通操作

透明ヘッダー、ページスワイプ、振動、入力中の遷移抑止、画面外タップでキーボードを閉じる動作を統一。

アクセシビリティ

ライト／ダーク、文字サイズ、VoiceOver、44–48ptのタップ領域、動きを減らす設定を確認する。

後回しにするもの：Live2D、Widget、情報源の大量追加、スキル自己生成。UX検証中に画面構造を増やさない。
04 / v1.3 voice conversation

音声は、既存FCAへ入るもう一つの入口

人格や記憶を音声専用に分けない。確定した文字起こしを通常のユーザーメッセージとしてFCAへ渡し、返答テキストと表情を保存してから読み上げる。

タップして話す常時盗聴せず、ユーザー操作で開始
文字起こし途中結果を入力欄へ表示、修正可能
既存FCA同じ記憶・感情・スレッドを利用
返答＋表情履歴へ通常どおり保存
シャノンが話す字幕を残し、タップですぐ中断
最初は半二重聞く時間と話す時間を分ける。割り込み可能な全二重は安定後に追加。
音声は保存しない初期設定では文字起こし後に破棄。会話履歴にはテキストだけを残す。
失敗しても文字で続く認識・読み上げ・回線のどれかが失敗しても、通常チャットへ戻れる。
予算を別管理文字起こし・会話LLM・読み上げを分け、1日上限と今回消費を可視化する。
バックグラウンド待受なし画面を離れたら録音停止。自発通知と常時マイクを混同しない。
話し方は状態の影響を受ける速さ・間・抑揚は穏やかに変化させるが、聞き取りやすさを優先する。
05 / Quality gate

ここまで通ったら、音声へ進む

✓ 主要8操作を迷わず完了
✓ 入力中に誤スワイプしない
✓ 対話画像・吹き出しが重ならない
✓ コピー・編集・再試行が発見できる
✓ ライト／ダーク／大きな文字で崩れない
✓ 既存履歴・記憶・接続が更新後も残る
✓ P0/P1の操作不具合が0件
✓ TestFlight実機で一巡確認

「完全に美しくなった」ではなく、基本操作の摩擦と致命的な違和感がなくなった時点を出口にする。細かな好みは実利用から次の小さな更新へ回す。
