画面

共通ナビ

トーク、メモリー、歯車を全ページの最上部に重ねる。背景は半透明で、スクロール内容が背後に残る。

トーク

状態行と説明文を削除。入力欄は「メッセージ」と送信ボタンだけの1段構成。

メモリー

「わたしが覚えていること」カードを削除。種類、記憶、根拠、操作だけを残す。

設定

状態と接続への導線を集約。チャット上部にあった状態・version・接続アイコンは置かない。

キーボード

会話面タップ、対話的スクロール、ページ移動のいずれでも入力状態を解除できる。

横移動

iOS標準ページングでトーク、メモリー、設定をスワイプでき、上部ボタンとも選択状態を共有する。

即時記憶

FCA
返信を先に返す。記憶抽出を待たない。
→
worker
軽量規則とLLMを組み合わせ、直接述べた情報だけを抽出。
→
共有状態
次の返答と「あなたについて」に反映。

対話試験

拾う「好きな食べ物は寿司」「好物はラーメン」「寿司が好き」「大きな音が嫌い」「結論から話してほしい」など。
拾わない質問、第三者の好み、伝聞、過去だけの好み、不確かな表現、一時的な出来事。
故障時即時LLMが失敗しても、感情更新と軽量規則による記憶更新は継続する。
実LLMgpt-5.6-lunaで27件を評価し、27件通過。試験は本番記憶を書き換えない。
