ライブ音声を再確認

iPhoneアプリの更新は不要です。AzureのRealtime搬送だけを修正し、バックアップ・APIテスト・再起動・データ維持確認まで完了しました。

サーバー側で完了したこと

  • 変更前ソースと本番DBを時刻付きでバックアップ
  • iPhoneのSDPを改変せず、標準FormDataでOpenAIへ転送
  • Azure上の型検査とAPIテスト163件に成功
  • APIだけを再起動し、worker／worldは継続稼働
  • DB整合性ok、会話・メッセージ・知識・作業件数を維持

実機で行うこと

  1. iPhoneで現在のShannon Build 38を開きます。TestFlight更新は不要です。
  2. 既存トークを一つ開き、音声ボタンを押します。
  3. 「今日はライブ音声の確認をしているよ」と自然な速さで話します。
  4. 自分の発話が途中から字幕として増えることを確認します。
  5. 話し終えた後、シャノンの字幕と音声返答が始まることを確認します。
  6. 音声画面を閉じ、やり取りが元のトーク履歴へ保存されたか確認します。

成功の目印

「ライブ音声に接続できませんでした」が出ず、自分のリアルタイム字幕、シャノンの返答字幕と音声、履歴保存まで動けば成功です。

まだ失敗する場合

  1. 再試行は一度だけにします。
  2. 設定の「音声診断」からログをコピーします。
  3. 画面に出た文言と診断ログを共有してください。音声本文・会話本文・鍵は診断へ保存されません。

安全な復帰：通常チャットはそのまま利用できます。アプリを削除したり、接続を解除したりする必要はありません。サーバー側は時刻付きバックアップから旧版へ戻せます。
