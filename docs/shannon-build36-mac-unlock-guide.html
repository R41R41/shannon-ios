Build 36 配信を再開するためのMacロック解除

目的は、完成済みのBuild 36をXcodeからAppleへ検証・アップロードすることです。コード、Azure、DBには追加変更を行いません。

手順

  1. Macの画面を表示し、ログインパスワードまたはTouch IDでロックを解除します。
  2. Xcodeが見えるデスクトップまで戻ります。
  3. このタスクに「ロック解除しました」と送ってください。
  4. 配信処理中は、完了の連絡までMacをスリープさせないでください。

成功の状態

こちらからXcodeのBuild 36アーカイブを開け、Appleへの検証とTestFlightアップロードを再開できます。

うまくいかない場合

画面がすぐ消える場合は、電源に接続したまま再度解除してください。Build 36のアーカイブは保存済みなので、再ビルドやデータ復旧は不要です。
