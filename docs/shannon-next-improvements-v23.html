03 / Gap analysis

あるものと、まだ足りないもの

領域現在次の改善
今日の関心表示はある現在は「最近観測した関心の先頭」。日ごとに選ばれ、理由と期限を持つシャノン自身の焦点へ変える。
自発性一本のループが稼働選定文が定型的。候補決定後だけ最大1回/日の低コスト生成を使い、自然な話しかけへ。
シャノン日記睡眠レポートから表示「何を覚えたか」中心から、「何が気になった／どう変わった」中心の短い一人称記録へ。
対話モードPresence Stage実装済み静止画を置いた印象をさらに減らし、聞く・考える・話すの状態、字幕密度、表情遷移を統合。
メモリー3面と編集は実装済み数値やDB一覧を主役にせず、「頭に浮かぶこと」「今日の焦点」「最近の変化」を先に見せる。
音声設計のみユーザー起動・半二重・字幕あり・音声非保存のMVPを実装。
Aether連携境界とAPIはある参照元の明示、提案レビュー、実データでの往復を完成。正本変更はAether側との連携要求が必要。

05 / One living loop

シャノンの自発性を一本につなぐ

観測会話・時間・探索結果
→
共有状態感情・記憶・関心
→
今日の焦点1日1件、理由つき
→
行動候補調べる・話す・待つ
→
一度だけ実行上限・静かな時間
→
日記何が変わったかを残す
重要：探索や15分ごとの判定にLLMは使わない。コードが話す価値のある候補を1件まで絞り、その時だけ自然な文面を生成する。返答FCAは待たせない。

07 / Build 24 definition of done

次の実装を「完了」と呼ぶ条件

画面

主要4状態を実機で確認

  • 空／短文／長文／通信失敗
  • スクロール／対話の切替
  • 入力中は誤遷移せず、外タップで閉じる
  • 作業タイルは注意が必要な時だけ前面化
アクセシビリティ

端末設定に負けない

  • 最大文字サイズで操作可能
  • VoiceOverの読み順とボタン名
  • Reduce Motionで静止
  • ライト／ダーク双方で十分なコントラスト
回帰

既存の大切なものを守る

  • 会話履歴・接続・メモリー維持
  • 表情とコピー
  • 複数トークと自動タイトル
  • Codex作業の進捗・許可・復帰
配信

TestFlightまでを一工程にする

  • ローカル全試験
  • Azure変更がある場合だけバックアップ配備
  • Xcode Cloud内部配信
  • Install／Smokeまで確認
08 / Cost guardrails

生きて見えても、働きすぎない

処理方式上限
RSS・天気・ニュース取得コードのみ情報源ごとの間隔、最大件数、90日保持
重複排除・話す価値の判定コードのみ候補80件以内、静かな時間、直近会話、1日1件
自然な自発メッセージ候補決定後だけLLM最大1回／日。背景予算が尽きたら定型送信せず沈黙
睡眠バッチ既存の背景LLM枠月次背景予算。今日の関心と日記を同じ結果から作り追加呼出しを避ける
通常会話FCAの固定モデル背景処理とは別予算。探索・感情・記憶を待たない
