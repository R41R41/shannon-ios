### 遅れの内訳と改善案（コメント → 声、中央値 12 秒 → 狙い 8 秒）

**測り方と限界。** 実モデルの台は、WSL の `keys.env` の Anthropic キーが無効で 401 になり、回せなかった（課金 0 円）。そこで次の 3 つから組み立てた。
