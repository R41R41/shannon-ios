Shannon · iPhone smoke guide · build 30

音声会話を、
一往復だけ確認する。

これはBuild 30の音声入力修正が実機で安定しているかを確かめるための短い確認です。会話履歴を汚したくなければ、新しいトークで行ってください。音声や会話本文は診断ログに保存されません。

対象: Shannon 0.1.0 (30)所要: 約2分Mac接続は不要
準備

始める前に

TestFlight上のShannonが Build 30 であることだけ確認してください。すでにBuild 30を使っていれば、更新や再インストールは不要です。

避けたいこと: 大事な会話の途中で試すこと、個人情報を話すこと、録音中にアプリを閉じること。音声が止まった場合も、アプリを再起動すれば通常チャットはそのまま使えます。

操作

この順で一往復

新しいトークを開く

できれば新しいトークを作成します。既存トークでも構いませんが、あとで確認しやすいよう音声テスト専用がおすすめです。

空の入力欄でマイクを押す

入力欄を空にして、右側の 音声で話す（マイク）を1回タップします。初回だけiPhoneがマイク利用を尋ねたら、許可を選びます。

聞いている… を確認して話す

波形と音声バーが表示されたら、3〜5秒ほど次の文を話してください。
こんにちは。今日は音声入力の確認をしています。短く返事をして。

文字が出たら送信する

話した文が音声バーに表示されたら、バー右側の上向き矢印をタップします。表示は 考えている… に変わります。

返答と読み上げを確認する

シャノンの返答が通常の会話として保存され、表示が シャノンが話している に変われば成功です。読み上げ中にもう一度右側のボタンを押し、音声を止められることも確認してください。

普通の会話へ戻れることを確認する

音声バーを閉じるか、入力欄へ短いテキストを打って送ります。アプリが落ちず、テキスト会話を続けられれば確認完了です。

成功条件

6つすべてなら合格

✓ マイクを押してもクラッシュしない
✓ 聞いている… が表示される
✓ 話した内容が短くても文字になる
✓ 上矢印で送信できる
✓ 返答が保存され、読み上げが始まる
✓ 読み上げ停止後も普通にチャットできる
うまくいかない時

結果に応じて、これだけ送ってください

起きたことまずすることこちらへ送るもの
マイクを押すと落ちるShannonを開き直し、歯車 → 音声診断 → 診断ログをコピーコピーした診断ログ全文。音声・会話本文・認証情報は含まれません。
許可されないiPhoneの「設定」→「Shannon」（または「アプリ」→「Shannon」）でマイクと音声認識を許可し、アプリへ戻る表示されたメッセージと、どちらの許可が見当たらないか
文字が出ない／送れない音声バーの × で閉じ、もう一度だけ試す最後に見えた表示（例: 聞いている、送信できます、考えている）
返答は出るが読み上げないテキスト会話が続くことを確認して終了返答は表示されたか、音声バーの表示は何だったか

クラッシュしても、アプリの削除や再インストールはしないでください。

会話キャッシュや端末の認証状態を守るためです。開き直して音声診断をコピーできれば、原因の段階を絞れます。

確認後は、結果を「6項目すべてOK」または上表の該当項目だけで教えてください。こちらでBuild 30の音声Smoke結果を記録し、次のUX監査へ進めます。
