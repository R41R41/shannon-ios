BOUNDARIES

自由に動く範囲はMacが決める

Project allowlistSHANNON_AGENT_PROJECTS_JSONに登録した別名だけを受理。iPhoneやLLMが送った任意パスは使わない。
Codex sandbox既定はworkspace-writeとon-request。範囲外操作はiPhoneで判断する。
Host identityAzureはTaskを受け取ったMacだけからEventを受理。他Hostによる進捗のなりすましを拒否する。
TransportAzureへはHTTPSの外向き通信。CodexへはMac内のstdio JSONL。WebSocketをインターネットへ公開しない。
Privacyコマンド出力全文はAzureへ送らない。ファイル名、増減行数、試験の成否、Codexの最終要約だけを投影する。
