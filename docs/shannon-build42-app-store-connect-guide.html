目的と現在地

確定commit d05aec9はGitHubのmainへ送信済みです。Release RunnerでAPI 172件、iOS 84件、Debug／ReleaseのiPhone向けビルドが成功しています。こちらからApp Store Connectは操作していません。

1. Xcode Cloudを確認

  1. App Store ConnectでShannon → Xcode Cloudを開きます。
  2. commitがd05aec9から始まる最新実行を選びます。
  3. 表示されたBuild番号を確認します。順番どおりなら42です。
  4. ArchiveとUploadが完了するまで待ちます。実行中なら重複して再実行しません。

2. TestFlightへ割り当てる

  1. TestFlight → iOSで同じBuild番号を開きます。
  2. Appleの処理が終わり「テスト可能」になるまで待ちます。
  3. 内部グループShannon Internalへ追加します。
  4. 外部テストやApp Store公開は選びません。

3. iPhoneで上書き更新

  1. iPhoneでTestFlight → Shannonを開きます。
  2. アップデートを押します。Shannonは削除しません。
  3. 更新後にShannonを起動し、既存トークと接続が残っていることを確認します。

4. 今回の必須Smoke

  • 入力欄をタップしてもクラッシュせず、キーボードが表示される
  • 1行と複数行の文字を入力し、入力欄が自然に広がる
  • 設定 → 外観 → ライトを選ぶと、設定画面を含めて明るい表示になる
  • 設定 → 外観 → ダークを選ぶと、設定画面を含めて暗い表示になる
  • iPhone本体をダークにした状態で「端末に合わせる」を選ぶと、Shannonもダークになる
  • 既存の会話履歴、接続、ライブ音声が維持されている

失敗したときの安全な戻り方

  • Buildが見つからない：Xcode Cloudの最新実行とcommit d05aec9を確認します。新しいcommitは作りません。
  • 処理中：数分待って再読込します。同じBuildを再送信しません。
  • 更新が出ない：Shannon Internalへの割当を確認し、TestFlightを下へ引いて再読込します。
  • クラッシュする：Shannonを削除せず、発生時刻と「入力欄をタップ直後」など直前操作だけを共有します。
  • 外観が変わらない：選んだ項目と、iPhone本体の外観設定を共有します。会話や接続の初期化はしません。

Apple側で表示されたBuild番号が42以外なら、その番号を正として共有してください。
