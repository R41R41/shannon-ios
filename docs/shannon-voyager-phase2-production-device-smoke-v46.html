SHANNON × VOYAGER · PHASE 2 · DEVICE SMOKE · 2026-09-09

既存Taskを、
確認してから更新する。

サーバー反映とiPhoneへの上書き導入は完了しています。 対象はShannon 0.1.0（2）の開発用実機版です。TestFlight版ではなく、App Store Connectにも変更を加えていません。

この確認では、Voyagerの未完了Taskを1件だけ選び、Shannon上で変更前後を確認してから反映します。ShannonはTaskを推測で選ばず、承認前にはVoyagerを書き換えません。

最初に1分だけ準備

  1. iPhoneのロックを解除し、ホーム画面を表示します。
  2. Voyagerを開き、消しても困らない未完了Taskを1件選びます。おすすめは実機確認用Taskです。
  3. そのTaskの現在のタイトルを、そのまま覚えるかコピーします。
  4. 重要なTask、完了済みTask、取消済みTaskは使わないでください。

実機で行う手順

Shannonを開く

既存のトークと会話履歴が残っていることを確認します。消えていた場合は、この先へ進まず報告してください。

更新したい内容を会話する

新しいトークで、次の形で送ります。○○だけVoyagerの正確なTask名へ置き換えてください。

Voyagerにある「○○」の詳細を「Shannon Phase 2の実機確認に成功」に更新して、合うProjectを選びたい。

整理を明示する

続けて、文字を足さずに次だけ送ります。

整理して

Voyager Task案カードが表示されれば次へ進みます。

既存Taskを1件選ぶ

  1. 確認して採用を押す。
  2. 反映方法を既存を更新へ切り替える。
  3. Task名で検索へ、先ほどのTask名の特徴的な語を入れて検索する。
  4. 候補のタイトル・状態・revを確認し、対象を1件だけ選ぶ。

同名候補が複数ある、候補が出ない、意図したTaskか判断できない場合は選ばず停止してください。

変更前後とProjectを確認する

  • 変更前がVoyagerの現在値と一致している。
  • Task名は意図しない変更になっていない。
  • 実行内容が「Shannon Phase 2の実機確認に成功」になっている。
  • Projectメニューから、実在する適切なProjectを1つ選ぶ。適切なものがなければProjectなしでも構いません。

問題なければこの内容を採用を押します。この時点ではまだVoyagerは変更されません。

承認前にVoyagerを確認する

Voyagerへ戻り、対象Taskの詳細とProjectがまだ変わっていないことを確認します。これは「確認だけでは書き換えない」安全性の確認です。

最後の反映を行う

Shannonへ戻り、採用した変更を反映を1回だけ押します。カードが反映済みになり、緑色で「Voyagerに更新」と表示されるまで待ちます。

Voyagerの正本を確認する

Voyagerで同じTaskを開き、詳細とProjectが選んだ内容へ変わっていることを確認します。これでPhase 2の実機確認は完了です。

成功の目印

Shannon

  • 既存履歴が保持
  • 候補検索が成功
  • 変更前とrevを表示
  • カードが反映済み

Voyager

  • 承認前は不変
  • 承認後に同じTaskを更新
  • 重複Taskなし
  • 他のTaskは不変

うまくいかない場合

  • エラーが出たら、反映ボタンを繰り返し押さないでください。
  • REVISION_CONFLICTなら、Voyager側で先にTaskが変わっています。新しい会話で改めて整理してから候補を作り直します。
  • TASK_NOT_EDITABLEなら、未完了の別Taskを選びます。
  • PROJECT_NOT_FOUNDなら、新しい整理カードでProjectを選び直します。
  • 接続エラー、クラッシュ、履歴消失なら、その画面のスクリーンショットと表示文を共有してください。アプリは削除しないでください。

サーバー側は配備前バックアップから復旧できます。revision確認と同一要求の重複防止があるため、失敗時に古い値を黙って上書きする設計にはしていません。
