SHANNON · BUILD 33

更新して、音声を
一度だけ確かめる

Build 33はiPhoneで録音だけを行い、Azureで文字起こししてから普段の会話へ渡します。Build 32まで落ちていた端末内リアルタイム音声処理は標準経路から外れました。

Shannon Internalへの配信完了

1. TestFlightから更新

  1. iPhoneでTestFlightを開く。
  2. Shannonを開き、表示がBuild 33か確認する。
  3. 「アップデート」があれば押す。Macやケーブル接続は不要。
  4. 更新後、Shannonを起動する。

2. 以前の内容を確認

  • シャノンへ接続済みのままになっている
  • 既存のトーク一覧と会話履歴が残っている
  • メモリーがこれまで通り開ける

3. アイコン表示を確認

  1. 設定 → アプリアイコンを開く。
  2. 現在のアイコンと、固定・自動・手動の各候補に実際の画像が出ることを確認する。
  3. この確認では変更しなくてもよい。

4. 音声を確認

  1. トーク画面で音声ボタンを押す。
  2. 8〜12秒ほど日本語で話す。
  3. 停止し、「聞き取っています…」を経て返答が出るまで待つ。
「次の休みに横浜へ行きたい。静かなカフェも探したいんだけど、どう思う？」

成功の見え方

  • 音声ボタンを押してもクラッシュしない
  • 話した内容の意味と「横浜」「静かなカフェ」が概ね正しく伝わる
  • 文字起こし後、通常のシャノンらしい返答が返る
  • 設定のアイコン候補に画像が表示される
  • 接続、既存会話、メモリーが維持されている

今回の既定モデルは費用を抑えたgpt-transcribeです。一字一句の一致より、固有名詞と発話の意味が自然に取れるかで判断します。日本語精度に不満があれば、アプリ更新なしでサーバー設定から別モデルを比較できます。

うまくいかないとき

  • クラッシュ：再度連打せず、Build番号と「音声ボタン直後／停止後／送信中」のどこだったかを知らせる。Build 32へ戻す必要はありません。
  • 聞き取れない：通信を確認し、5〜15秒の音声で一度だけ再試行する。長時間録音や連続送信はしない。
  • 接続や履歴が消えた：再ペアリングや削除を行わず、その画面のまま知らせる。Azureのバックアップから調査できます。
  • アイコン画像が空白：設定画面のどの行が空白かを知らせる。アイコン自体は変更しなくてよい。

音声ファイルは文字起こし後に破棄され、会話本文・音声・認証情報は診断ログへ記録しません。
