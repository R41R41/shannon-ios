更新手順

成功チェック

  • 以前のトークと会話内容が残っている
  • シャノンへ短いメッセージを送り、返答できる
  • 上部が「メニュー／現在のトーク名／新規トーク」の構成になっている
  • メニューがスライドして現れ、「トーク一覧・頭の中・作業・設定」を開ける
  • シャノンの表情アイコンが以前より少し大きい
  • ユーザー発言が淡い青の吹き出しで表示される
  • ライト／ダークの両方で文字が読みやすく、Clear Signalの青が自然に見える
  • Realtime音声を一度だけ短く開始し、接続・発話字幕・返答音声が動く

うまくいかない時

  • Build 39が見えない：TestFlightを終了して開き直すか、数分待ってページを再更新します。
  • 会話や接続が消えた：アプリを削除・再接続せず、その画面で止めて状況を教えてください。
  • Realtime音声が失敗：設定の音声診断からログをコピーしてください。音声・本文・鍵は記録されません。
  • 表示崩れ：個人的な会話本文を隠したスクリーンショットと、ライト／ダークのどちらかを教えてください。
