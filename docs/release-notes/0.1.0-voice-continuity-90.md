# Shannon iOS 0.1.0 — voice continuity and controls

Candidate: Xcode Cloud next build 90 (latest verified build/run: 89).

## Changes

- Give Jev the same-thread recent context and raw recognition result, and score semantic transcript reliability. Below 0.85, or if speech scoring is unavailable, use the response LLM for bounded contextual interpretation. This is not acoustic confidence; consequential ambiguity requires confirmation and cannot authorize a task or external mutation.
- Keep chronological, unanswered speech and typed input when a new utterance cancels response generation or playback. Retry reuses the same input identity; a completed response acknowledges only its frozen input prefix. Stale response/session callbacks cannot change the replacement turn.
- Keep microphone, photo, and participant controls visible with labels and accessible hit targets. Use a native multiline composer above the keyboard, and replace the bottom spotlight/progress decoration with a small, actual microphone level indicator. Camera preview, guest isolation, existing Waterlight expression, TTS prefetch/FIFO, and +50-cent voice remain intact.

## Verification

Deterministic API, cognitive/evaluation, shared Swift, generic iPhone Debug, Mac tests, and Release Runner checks pass. Synthetic Simulator render verification is separate from a physical microphone/camera/participant interaction smoke test. The new semantic confidence threshold has not yet been calibrated against labeled real speech; no live paid model evaluation is claimed.
