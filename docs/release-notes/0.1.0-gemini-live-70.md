# Shannon iOS 0.1.0 (70) — Gemini 3.8 Live

## Scope

- Add an explicit `Gemini 3.8 Live · リアルタイム実験` beside OpenAI Live and the
  Gemini Flash-Lite turn-based comparison.
- Stream microphone PCM directly from iPhone to Gemini and play native 24 kHz audio
  with continuous turns, live captions, barge-in, reconnect/resumption, and Shannon
  backend delegation.
- Show the selected model/voice, first-audio latency, interruption latency, and an
  estimated running session cost on the experiment screen.
- Keep the permanent Gemini API key in Azure's mode-0600 secret file. The paired app
  receives only a one-use ephemeral token constrained to `gemini-3.8-live` audio.

## Cost baseline

The displayed estimate uses $0.005 per input-audio minute and $0.018 per
output-audio minute. A cycle with 30 seconds of user speech and 30 seconds of Shannon
speech is about $0.0115, excluding Shannon backend/tool calls. The existing
Flash-Lite cascade estimate for the same split is about $0.00675 plus the ordinary
Shannon text model/tool cost. OpenAI Live remains displayed against its existing
$0.05 active-minute baseline.

## Provider smoke

Using the production Azure key without exposing it, token issuance took 293 ms and
the synthetic Japanese Aoede test reached first audio 2.82 seconds after token
provisioning began. Audio PCM and output transcription were both received. Physical
iPhone measurements remain the authority for microphone-end-to-first-speaker latency,
echo cancellation, and interruption feel.

## Release gates

Local API tests, Swift tests, a generic iPhone build, Azure deployment/health, Xcode
Cloud archive/upload/processing, internal-group assignment, TestFlight installation,
and physical-device voice smoke are tracked as separate gates.
