# Shannon iOS 0.1.0 (68) — Gemini turn-based voice experiment

## Scope

- Keep the existing OpenAI Live experience unchanged and selectable.
- Add an explicit `Gemini 3.8 Flash-Lite · 試験版` mode from the voice button.
- Record one bounded turn, use the existing authenticated transcription and
  Shannon text/history/tool lane, synthesize the persisted reply on Azure, and
  play the returned 24 kHz WAV on iPhone.
- Keep the Gemini API key, model, voice, and style on Azure. The Apple client
  receives only bounded audio plus non-secret model, voice, duration, and
  estimated-output-cost headers.
- Default the first device experiment to `gemini-3.8-flash-lite-tts` with the
  prebuilt `Leda` voice. A custom Shannon voice remains a separate listening
  decision after physical-device comparison.

## Cost baseline

Through 2026-12-31, Flash-Lite output is estimated at $0.0015 per 10 seconds
($0.009 per output minute), while Flash is $0.00225 per 10 seconds ($0.0135 per
output minute). A 30-second user turn plus 30-second Flash-Lite reply is about
$0.00675 for transcription and TTS, plus the ordinary Shannon text-model and
tool cost. Gemini TTS output prices double on 2027-01-01.

Azure deployment and a real Gemini synthesis must succeed before this build is
published. Xcode Cloud Archive, Upload, Processing, `Shannon Internal`
assignment, TestFlight installation, and physical-device voice smoke remain
separate gates and must not be inferred from the local build.
