# Shannon Desk 0.1.0 (12)

Release identity: macOS 0.1.0 (12)

## User-facing changes

- Prevents the development screen from crashing while restoring the previously open inspector.
- Keeps the current-location inspector, its normal animation, and the previous window state across launches.
- Keeps diff line coloring and text selection while rendering very large diffs lazily to avoid layout overload.

## Verification

- Fast repository, icon, semantic-role, and architecture checks pass.
- Mac Debug tests pass: 19 XCTest tests and 4 Swift Testing tests.
- A 12,000-line diff regression test preserves every line and stable identity.
- The restored development-screen and inspector condition remained running beyond the original crash interval without an AppKit constraint exception.
- The unsigned universal macOS Release build succeeds for arm64 and x86_64.

## Distribution boundary

- Archive, upload, processing, internal-group assignment, TestFlight installation, and physical-device smoke are tracked as separate release gates.
