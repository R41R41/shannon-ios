# Shannon iOS 0.1.0 (72) — Gemini Live audio callback crash repair

## Incident

Build 71 reached the physical-iPhone Voice Processing I/O microphone path, but
crashed on its first realtime audio callback. The device crash report recorded
`SIGTRAP` in `_swift_task_checkIsolatedSwift` on `AURemoteIO::IOThread`.

## Root cause and repair

`ShannonGeminiLiveTransport` is MainActor-isolated. Build 71 constructed its
`AVAudioSinkNode` callback inside that actor, so Swift inherited MainActor
isolation for a closure that AVFoundation necessarily invokes on the realtime
audio thread.

Build 72 constructs the sink callback in an explicitly `nonisolated` factory.
PCM conversion, chunking, VAD, and queue submission remain on the audio callback;
only observable UI state crosses to MainActor through an explicit task. The
Voice Processing I/O graph, 16 kHz mono PCM, 100 ms chunks, Gemini/Aoede voice,
subtitles, interruption, resumption, history, and other voice modes remain intact.

Privacy-bounded setup checkpoints were added before and after graph connection,
engine start, and player start so a future AVFoundation failure has a precise
last-completed step without recording audio, transcripts, messages, tokens, or
credentials.
