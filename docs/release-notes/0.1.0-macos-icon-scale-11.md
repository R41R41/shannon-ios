# シャノン 0.1.0 (11)

Release identity: macOS 0.1.0 (11)

## User-visible fixes

- Uses the user-facing name「シャノン」in Finder and the macOS menu bar while preserving the internal `ShannonDesk` target and scheme.
- Sizes L02, L06, and L10 to 84.375% of the macOS icon canvas, matching the visual footprint of standard Mac apps instead of filling the full canvas.
- Keeps transparent outer space and rounded corners for the compiled icon, live icon switching, and launch restoration.
- Includes the Build 10 launch-crash fix that restores a saved non-default Dock icon before the first window rather than from a SwiftUI scene task.

## Evidence and boundaries

- The deterministic icon generator and fast verification gate reject a Mac icon whose visible alpha bounds do not match the approved footprint.
- The iOS icon masters and iOS asset catalogs remain unchanged.
- Archive, upload, App Store Connect assignment, TestFlight installation, and physical-device smoke are not part of this source change.
