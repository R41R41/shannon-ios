# Shannon Desk 0.1.0 (10)

Release identity: macOS 0.1.0 (10)

## User-visible fixes

- Fixes the launch crash caused by restoring the Dock icon from a SwiftUI scene task while AppKit was updating window constraints.
- Keeps L06 as the compiled default icon and restores a saved L02 or L10 choice once, before the first window is created.
- Gives every macOS icon size transparent rounded corners instead of shipping an opaque square canvas, including live L02/L06/L10 switching and launch restoration.

## Evidence and boundaries

- The build 9 crash was reproduced in both the installed TestFlight app and the local Design Preview as an AppKit `NSGenericException` for repeated window constraint updates.
- Removing the scene task kept the same Design Preview alive beyond the previous crash interval.
- The iOS icon masters and iOS asset catalogs are unchanged.
- Archive, upload, App Store Connect assignment, TestFlight installation, and physical-device smoke are not part of this source change.
