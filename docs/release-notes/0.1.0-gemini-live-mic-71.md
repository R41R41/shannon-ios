# Shannon iOS 0.1.0 (71) — Gemini Live microphone repair

## Scope

- Preserve OpenAI Live, Gemini Flash-Lite, and the Gemini 3.8 Live conversation UI.
- Replace Gemini Live's microphone tap with the physical-iPhone-safe Voice Processing
  I/O graph already proven by Shannon's OpenAI Live path.
- Explicitly enable duplex input/output, read the microphone's Voice Processing format
  from bus 1, and connect the input node through its sole graph output so live-looking
  sessions cannot silently capture zeroed PCM.
- Convert capture to mono 16 kHz Float32 in the audio graph, then send raw 16-bit
  little-endian PCM to Gemini in 100 ms chunks.

## Regression boundary

The Gemini model, Aoede voice, ephemeral-token boundary, server VAD, subtitles,
barge-in, reconnect/resumption, backend delegation, history commit, and cost/latency
display remain unchanged. No permanent provider credential is added to the app.

## Release gates

Swift protocol/chunking tests and a generic iPhone Debug build must pass before the
full deterministic verification and unsigned Release build. Xcode Cloud archive,
upload, processing, internal-group assignment, TestFlight installation, and the
physical-device Gemini microphone smoke are tracked independently.
