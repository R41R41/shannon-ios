# 0.1.0 — voice continuity retry, candidate Build 91

Build 90's Xcode Cloud archive failed when downloading the pinned official WebRTC
dSYM asset: curl reported a TLS receive connection reset (exit 35). Compilation
and the signed local Release build passed; no TestFlight delivery of 90 occurred.

The archive download now retries all transfer failures for this idempotent public
asset, with three retries, a 20-second connection timeout, a 120-second attempt
timeout, and a 180-second retry-start budget. An already-running final attempt
can extend past that budget, but total transfer time remains bounded. File output,
the pinned SHA-256, framework/dSYM UUID matching, and all required symbol payloads
remain mandatory. No archive or symbol-validation phase is disabled.

The voice recognition context, interrupted-input retention, and voice UI changes
are unchanged from the Build 90 candidate. New semantic-confidence calibration,
physical-device interaction checks, and TestFlight installation remain separate
verification steps; successful local builds do not establish these outcomes.
