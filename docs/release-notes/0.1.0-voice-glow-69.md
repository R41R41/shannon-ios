# Shannon iOS 0.1.0 (69) — Voice state glow

## What changed

- Replaced the large center pulse in OpenAI Live with a bottom-edge native SwiftUI glow that reacts to the existing microphone and pitched playback buffers.
- Added listening, thinking, speaking, connecting, idle, and failure treatments while keeping the Waterlight Eye, visible status, subtitles, and controls as the semantic authority.
- Applied the same state grammar to the Gemini turn-based voice experiment without opening a second audio capture path.
- Added static, state-specific rendering for Reduce Motion plus reduced-transparency and increased-contrast adaptations.

## Privacy and behavior

The OpenAI Live glow samples a transient RMS envelope at 30 Hz from buffers already flowing through the WebRTC audio device. PCM is not retained or logged. Muting immediately suppresses microphone-driven motion.

## Verification before distribution

- `sh scripts/verify.sh fast`
- `swift test --skip-build`
- `sh scripts/verify.sh app`

Archive, upload, App Store Connect processing, `Shannon Internal` assignment, install, and physical-device smoke are tracked as separate release gates.
