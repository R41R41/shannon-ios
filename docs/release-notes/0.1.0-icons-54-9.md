# シャノン 0.1.0 アイコン更新

Release identity: iOS 0.1.0 (54) / macOS 0.1.0 (9)

## 変更

- アプリアイコンを監査済みのL02、L06、L10へ更新しました。
- L06をインストール時の標準・おすすめとして使用します。
- 設定から選んだアイコンを端末内に保存し、次回起動後も維持します。
- アプリの表示名は引き続き「シャノン」です。
- `ShannonAppCore` のPackage解決をiOS／Mac共通Workspaceへ一本化し、起動前検査付きの
  `Open Shannon in Xcode.command` を追加しました。

## 自動検証

- L02／L06／L10の全iOS・macOS AppIconセットが監査済みパッケージとバイト一致。
- iOSの既定L06、代替L02／L10、表示名、選択保存と不明値からL06への移行を検証。
- 共通Workspace、3つのPackage lock、両Schemeの `ShannonAppCore` 解決を検証。
- API 288件、Swift 129件、Mac XCTest 19件＋Swift Testing 3件、Release Runner 6件が成功。
- iOS Debug／ReleaseおよびMac Debug／Release（arm64＋x86_64）の署名なしビルドが成功。
