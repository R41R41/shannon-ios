詳細と操作

「そう思った根拠」「確信度」「記憶の履歴」を先に示し、その下に操作を置く。忘却と否定は確認ダイアログを必須にした。

固定訂正忘れる事実ではない復元

操作の意味

訂正元データを破壊せず、ユーザーの正しい表現をoverrideとして保存。プロンプト・一覧は訂正版を使い、根拠と変更理由を残す。
忘れるforgottenとして会話生成から除外。睡眠バッチも同じ内容を自動再学習しない。あとから復元可能。
事実ではないrejectedとして強い否定境界を保存。同じ候補が再登場しても採用せず、睡眠レポートの矛盾として可視化。
固定重要な記憶を一覧とプロンプトで優先。思い出は通常の想起から外れてもactive memoryに維持する。
復元非表示・否定状態をactiveへ戻す。訂正表現は保持するため、復元で古い誤りへ巻き戻らない。

睡眠後に見える4つ

新しく覚えた

初めて明示された、持続的なユーザー情報または望ましい関わり方。

理解が深まった

同じ内容が再確認され、確信度が上がったこと。上限を設けて断定を避ける。

興味が動いた

「最近〜に興味がある」のような明示情報だけを、シャノンの関心へ反映。

矛盾を保留した

現在理解と反対の発言、またはユーザー境界に反する候補。自動上書きせず両方を表示。
