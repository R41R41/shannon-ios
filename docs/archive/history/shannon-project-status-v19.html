04 / v1.1 implemented

実装した2機能

実装済み 1

自動配信失敗時だけ通知

成功時や定期確認時は通知しない。同一障害は最初の1回だけ、シャノンの短い言葉で知らせる。

通知条件連続失敗の最初、または原因が変わった時だけ。
重複防止障害fingerprintと通知済み時刻を保存。10分ごとの同じ失敗は黙る。
復旧成功で障害状態を閉じる。復旧通知は既定OFF、履歴だけ更新。
遷移先通知タップで「設定 → アプリの更新」を直接開く。
本文生ログや鍵情報は出さず、「新しいビルドの配信で少しつまずいてる」のように表示。
