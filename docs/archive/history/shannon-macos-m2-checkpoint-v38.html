Shannon Desk · M2操作基盤チェックpoint · 2026-09-08

Macらしく、探して、移動して、続きから。

新しい画面を増やさず、既存の会話・作業全体・頭の中をキーボードで横断し、アプリを閉じても同じ場所から再開できるようにしました。

今回できたこと

すぐ検索

⌘F でどの画面からでもトーク検索へ移動。大文字小文字、全角半角、アクセント記号の差を吸収します。Enterで先頭結果を開き、Escで検索を消去します。

すぐ移動

⌘1 会話、⌘2 作業全体、⌘3 頭の中、⌘4 設定。⌘⌥I で現在地インスペクタを開閉します。

続きから再開

前回開いていた面、選択中のトーク、現在地インスペクタの開閉をシーン単位で保存。終了・再起動後にも作業の文脈を戻します。

視覚確認

デザイン用の安全なオフラインデータで確認。検索語「shannon」により、対象トークだけが残っています。

次の画面は ⌘2 で移動し、アプリを終了・再起動した後にも復元された「作業全体」です。

  • Mac Debug build + 7 unit tests: 合格
  • 検索の全角半角・大文字小文字・アクセント記号: 合格

境界と次

変更はMac専用の apps/macos-app/** とこの記録だけです。iPhone、共有コア、API、DB、署名、GitHub、App Store Connect、TestFlightには触れていません。
