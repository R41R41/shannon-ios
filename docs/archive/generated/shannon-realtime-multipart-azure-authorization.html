Realtime音声接続のAzure反映

Build 37がOpenAIへ接続できない原因を直したAPIファイルを、本番Azureへ安全に反映します。iPhoneアプリの再配信や再インストールは行いません。

実施すること

  1. 現在のAzure API稼働状態とヘルスを記録します。
  2. 変更対象のAPIソースを日時付きでバックアップします。
  3. Realtime接続処理と対応テストだけを転送します。環境変数、APIキー、会話DBは上書きしません。
  4. Azure上で型検査と対象テストを実行します。
  5. APIサービスだけを再起動し、ヘルス、起動ログ、通常チャットの接続を確認します。

あなたにお願いすること

内容に問題がなければ、Shannonとのトークに次の一文を送ってください。

Realtime音声修正のAzure転送・対象ファイルのバックアップ・APIテスト・APIサービス再起動を許可します

反映完了後は、現在のTestFlight Build 37で音声ボタンを押して確認できます。

成功の状態

Azureのヘルスが正常で、OpenAIがSDP回答を返し、Build 37が「ライブ音声に接続できませんでした」から音声会話画面へ進む。

失敗した場合の安全な復旧

  • テストまたは起動確認が失敗した場合は、バックアップした直前のAPIファイルへ戻します。
  • 同じAPIサービスだけを再起動し、ヘルスと通常チャットを再確認します。
  • SQLite、会話履歴、端末のペアリング、TestFlightアプリは変更しないため、そのまま保持されます。
Realtime接続確認では少量のOpenAI API利用が発生する可能性があります。秘密情報や音声本文をログ・資料へ保存しません。
