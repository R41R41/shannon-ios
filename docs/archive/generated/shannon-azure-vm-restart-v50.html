Shannon Azure VMを起動する

Voyager整理画面の重複カード修正を本番へ反映する前提として、停止中のShannonサーバーを安全に起動します。

現在の状態

2026年9月10日、公開APIとSSHの両方がタイムアウトしています。ローカル修正とAPI 197件の検証は完了しており、VM起動後はこちらでバックアップ、反映、再起動、確認を続行できます。

操作手順

  1. Azure Portalを開きます。
  2. 仮想マシン vm-constant を選びます。
  3. 状態が「停止済み（割り当て解除済み）」なら、上部の「開始」を1回だけ押します。
  4. 状態が「実行中」になるまで待ちます。
  5. このCodexタスクへ「起動しました」と送ります。

成功の見え方

Azure Portalで vm-constant が「実行中」になります。その後、こちらでShannon API、worker、world、Voyager API、データ整合性を確認します。

うまくいかない場合

  • 「開始」を連打しないでください。状態更新を一度待ちます。
  • 開始に失敗した場合は、表示されたエラー文だけを共有してください。認証コード、鍵、APIキーは共有しません。
  • 別のVMは操作せず、対象が vm-constant であることを再確認します。
