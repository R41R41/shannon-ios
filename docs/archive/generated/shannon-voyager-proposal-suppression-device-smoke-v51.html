重複カードが消えたことを確認する

Voyager更新の相談ではShannon自身の「作業を始める」カードを出さず、明示的な「整理して」の後にVoyager Task案だけを表示する修正の実機確認です。アプリ更新は不要です。

手順

  1. iPhoneのShannonで新しいトークを作ります。
  2. 次を送ります。
    Voyagerにある「シャノンとVoyagerの実機連携を確認する」の詳細を「Shannon Phase 2の実機確認に成功」に更新して、合うProjectを選びたい。
  3. Shannonの通常返信の直後を確認します。
  4. 続けて 整理して と送ります。
  5. Voyager Task案が1件表示されたところで止めます。今回は「整理を完了」や最終反映は不要です。

成功

最初の依頼後に「作業を始める／今はやめる」カードが出ない。

「整理して」の後には、確認・採用するためのVoyager Task案だけが出る。

メッセージに付く「対話」表示は通常の会話種別なので、そのままで正常です。

失敗時の安全な戻り方

上段の「作業を始める」カードが再び出た場合は、押さずに画面を共有してください。

Voyager Task案の最終反映もしないでください。サーバー変更前のソースとDBはバックアップ済みで、必要なら安全に戻せます。
