Shannon Build 41

App Store ConnectでApple側の処理を確認し、Shannon Internalへ安全に配信します。

GitHub main送信済み · Apple側確認はユーザー対応

目的と現在地

確定commit b37423d はGitHubのmainへ送信済みです。API 172件、iOS 84件、Debug／ReleaseのiPhone向けビルドも成功しています。ここから先のApp Store Connect操作だけを行います。

1. Xcode CloudのBuild 41を確認

  1. App Store ConnectでShannonを開きます。
  2. Xcode Cloudを開き、最新の実行を選びます。
  3. 対象がBuild 41で、ソースのcommitがb37423dから始まることを確認します。
  4. ArchiveとUploadが完了するまで待ちます。進行中なら追加実行や再送信はしません。

2. TestFlightのApple処理を確認

  1. ShannonのTestFlight → iOSを開きます。
  2. 0.1.0 (41)が表示されるまで待ちます。
  3. 「処理中」の場合は、そのままAppleの処理完了を待ちます。
  4. Build 41を開き、輸出コンプライアンスなどの確認が表示された場合だけ、既存Buildと同じShannonの回答方針で完了します。

3. Shannon Internalへ追加

  1. Build 41のグループまたはテスター欄を開きます。
  2. 内部グループShannon Internalを追加します。
  3. ステータスがテスト中になり、Shannon InternalにBuild 41が表示されることを確認します。

外部テスト、App Store審査、公開配信は今回の対象ではありません。

4. iPhoneで更新

  1. iPhoneでTestFlight → Shannonを開きます。
  2. アップデートを押します。
  3. Shannonの設定やTestFlightの表示で0.1.0 (41)を確認します。

Shannonを削除しないでください。既存の会話・接続情報を保ったまま上書き更新します。

成功の目安

  • Xcode CloudのBuild 41でArchiveとUploadが成功している
  • TestFlightのBuild 41でApple処理が完了している
  • Build 41がShannon Internalに割り当てられている
  • iPhoneのTestFlightからBuild 41へ更新できる

更新後の簡易確認

  • 既存のトーク、会話履歴、シャノンへの接続が維持されている
  • Talk本文が画面の上下端まで続き、時刻・ホーム表示はグラデーションで読める
  • 入力欄が文字量に合わせて広がり、送信できる
  • 見出し、箇条書き、引用、コードがMarkdownとして読みやすく表示される
  • 返信のコピーができる
  • 画面左側から右へスワイプするとサイドバーが開く
  • ライブ音声が接続でき、字幕・音声返答・履歴保存が保たれている

うまくいかない場合

  • Build 41がない：Xcode Cloudで実行中か失敗かを確認し、同じビルドを重複起動しないでください。
  • TestFlightが「処理中」：通常は待つだけです。数分後に再読込します。
  • Shannon Internalに追加できない：Build 41のApple処理完了と、内部グループを選んでいることを確認します。
  • iPhoneに更新が出ない：TestFlightを下へ引いて再読込し、数分待ちます。
  • 失敗表示がある：画面、Build番号、表示された文言をそのまま共有してください。Shannonは削除しません。
