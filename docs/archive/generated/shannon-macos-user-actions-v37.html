Mac実接続とApp Store準備

このページは、ローカル実装が配布準備へ進んだ時にユーザー側で行う作業を先に具体化したものです。現時点では、まだ実行する必要はありません。

1. MacをShannonへ接続する

目的

Mac自身へ期限付き・端末固有の接続資格を発行し、iPhoneと同じ会話・記憶・作業へ安全に接続します。

手順
  1. 信頼済みのShannon接続画面で「新しい端末を接続」を選びます。
  2. 端末名を「このMac」など識別可能な名前にします。
  3. Macで発行された shannon://connect/... リンクを開きます。
  4. Shannon Deskの左下が「接続済み・このMac」になったら開き、「接続を確認」を押します。
成功の見え方

「認証された通信」が「確認済み」になり、既存のトーク一覧が表示されます。iPhone側の履歴も消えません。

失敗した時

通信失敗ならMacのネット接続を確認して「接続を確認」を再度押します。401／無効表示なら資格は破棄されるため、新しい接続リンクを発行します。接続リンクやtokenをチャット、Git、HTMLへ貼らないでください。

2. App Store ConnectへmacOSを追加する

目的

新しい別製品を作らず、既存Shannon app recordにMac版を追加します。

手順
  1. App Store Connectで既存のShannonを開きます。
  2. App情報から「＋ Platform」を選び、macOSを追加します。
  3. Mac targetが既存と同じbundle ID com.r41r41.shannon を使っていることを確認します。
  4. macOS固有の説明、スクリーンショット、プライバシー情報を入力します。
  5. 最初のMac buildがアップロードされるまでは公開提出しません。

Apple公式: Add platforms

成功の見え方

既存Shannonのページ内にmacOSタブが追加され、iOSのapp recordと同じApple ID配下で管理できます。

失敗した時

別のapp recordを新規作成しないで止めます。bundle ID競合、契約、権限、SKUのエラー画面をそのまま保存し、Shannonの作業へ戻してください。既存iOS版の設定を削除・置換しないでください。

安全境界

  • 証明書、秘密鍵、API key、接続tokenは資料やGitへ入れません。
  • 署名、Keychain、App Store Connect、TestFlightはiPhone作業とMac作業で同時に操作しません。
  • 公開提出・自動配信は、Mac実API smokeと内部テストが終わってから別の明示作業にします。
