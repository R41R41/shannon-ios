01 · PRODUCT DECISIONS

ここまでを仕様として固定する

NAVIGATION

Agentタブは作らない

既存の「トーク／メモリー／設定」とスワイプ遷移を維持。作業は会話内カードから開く。

MOBILE ROLE

iPhoneはRemote

状況、計画、承認、追加指示、中断、結果に集中。ターミナル全文は通常表示しない。

AGENT ROLE

Codexは交換可能なWorker

Shannonが意図と人格を持ち、AdapterがCodex固有プロトコルを吸収する。

v1.1では、作業開始前に必ず「始める」をユーザーが押す。曖昧な会話から勝手にコードを変更しない。
同じMacで同時実行する作業は最初は1件。複数作業はキューに積み、並列化は実測後に判断する。
会話LLMの1回の応答に構造化されたtaskProposalを含め、分類専用の追加LLM呼び出しは増やさない。
作業終了時にShannonへ残すのは要約・判断・既知問題・ユーザー方針だけ。Codexの生ログを長期記憶に入れない。
任意HTMLをAIに生成させず、許可済みUIブロックだけをSwiftUIで描画する。

4 · 結果
作業中の常設表示トーク入力欄の直上に高さ44pt程度の「作業カプセル」を1つだけ表示。タップで作業画面へ。会話本文を隠さず、入力中の横スワイプ禁止ルールも維持する。
作業画面の情報順シャノンの一文 → 現在の行動 → タイムライン → 必要な判断 → 変更・試験結果。内部処理名や生ログを最上部に置かない。
戻り方左上の戻る操作で元のトークへ。作業画面ではトーク／メモリーの横スワイプを無効化し、誤操作を防ぐ。
表情調査＝thinking、実行＝determined、承認待ち＝concerned、完了＝joyful、失敗＝wry。イベントごとに固定保存し、後から感情が変わっても過去表示を変えない。

←
7 · 報告結果カードを会話へ保存。必要ならAPNs。

LLM費用の境界：作業カードの状態更新、ポーリング、イベント整形、重複排除、通知判定にはLLMを使わない。LLMを使うのは通常のShannon会話と、ユーザーが明示的に開始したCodex作業だけ。
04 · SYSTEM ARCHITECTURE

Azureを中継し、Macへ外から穴を開けない

iPhone · Shannon

  • 会話と作業カード
  • Task Room
  • 承認・追加指示・中断
  • APNsとDeep Link
⇄

Azure · Shannon API

  • 既存ペアリング認証
  • Task Store / Event Projection
  • Command Broker
  • 通知と再接続状態
⇄

Mac · Shannon Agent Host

  • 外向きHTTPS long-poll
  • Codex Adapter
  • App Serverをstdio起動
  • project allowlist / sandbox
通信方式 v1Hostは25秒のlong-pollで命令を取得し、イベントをバッチ送信。iPhoneは作業画面表示中だけafterSequence付きで2秒間隔、非表示時は停止。承認と完了はAPNsを使う。
Codex接続Hostがcodex app-serverを子プロセスとして起動し、安定したローカルstdio JSONLで接続。外部公開用WebSocketへ直接iPhoneをつながない。
再接続Host再起動後は未完了Taskを読み、外部thread IDがあればthread/resume。進行中turnを復元できなければ「中断後、再開可能」としてユーザーへ明示する。
OpenAI公式文書ではApp ServerのWebSocket transportはexperimentalかつproduction非対応。したがって本設計は、App Server自体を外へ公開せず、ローカルstdioの前にShannon Hostを置く。

冪等性開始・追加指示・中断・承認すべてに端末生成のidempotencyKeyを必須化。通信再試行で同じCodex命令を二重実行しない。
イベント順序Hostごとの受信順ではなくTaskごとの単調増加sequenceをAPIが採番。重複event IDは無視し、欠番時はHostへ再送要求。

Codex Adapterthread/start・thread/resume、turn/start、turn/steer、turn/interrupt、item/turn通知、approval requestをShannonの共通Eventへ変換する。

08 · SAFETY, PRIVACY, COST

「自由に動ける」と「勝手に動く」を分ける

Project allowlist

Host設定に登録した絶対パスだけをcwdにできる。iPhoneやLLMが任意パスを指定しても拒否。

Approvalは縮小のみ

Codexが提示した選択肢をそのまま許可範囲として扱い、Shannon側が勝手に広げない。

通知は秘密を載せない

ロック画面には「判断が必要」「作業が完了」まで。コマンド・ファイル名・Diffはアプリ内だけ。

LLM予算を分離

Shannon会話、Codex作業、背景活動を別レーンで計測。作業開始前にモデル・上限をTaskへ固定。

停止条件

日額上限、連続失敗、Host切断、approval timeout、ユーザー中断で即停止。自動再開はしない。

短期ログ

Terminal全文や大きなDiffはMac正本。Azureは要約と参照を基本にし、必要な一時本文には期限を持たせる。
