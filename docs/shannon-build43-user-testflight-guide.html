SHANNON · USER-OPERATED RELEASE

0.1.0 (43) を
TestFlightへ配信する

Build 42の安定性を土台に、Voyager Phase 2の意味安全修正と重複カード抑止を含む安定候補です。XcodeとApp Store Connectの外部操作だけを、あなたが行います。

AppShannon
Version0.1.0
Build43
GroupShannon Internal

1. XcodeでArchive

  1. apps/ios-app/ShannonApp.xcodeproj をXcodeで開く。
  2. Schemeが ShannonApp、実行先が Any iOS Device (arm64) であることを確認する。
  3. Target → GeneralでVersion 0.1.0、Build 43 を確認する。
  4. Signing & Capabilitiesは既存のAutomatic SigningとTeamを維持する。Bundle IDは変更しない。
  5. メニューの Product → Archive を選ぶ。

成功：Organizerに Shannon 0.1.0 (43) のArchiveが1件表示されます。

2. App Store ConnectへUpload

  1. Organizerで今作ったArchiveを選び、Distribute Appを押す。
  2. App Store Connect → Upload を選び、既定の自動管理設定のまま進む。
  3. 検証結果に問題がなければUploadを実行する。

成功：Upload完了が表示され、App Store ConnectのTestFlightでBuild 43が処理中になります。

3. TestFlight内部配布

  1. App Store Connect → Shannon → TestFlight → iOS を開く。
  2. Build 43が「テスト準備完了」になるまで待つ。
  3. 必要なら輸出コンプライアンスで、アプリが非免除暗号を使用しない旨を確認する。
  4. Build 43を内部グループ Shannon Internal に追加する。

成功：Shannon Internalのテスターに0.1.0 (43)が表示されます。

4. iPhoneで更新・安定確認

  1. アプリを削除せず、TestFlightからBuild 43へ更新する。
  2. 既存の接続、トーク履歴、設定が残っていることを確認する。
  3. 既存トークを開き、入力欄をタップして短い通常会話を1往復する。
  4. 外観を「端末に合わせる／ライト／ダーク」で切り替える。
  5. Voyager更新依頼では「作業を始める」カードが重複せず、整理して 後にVoyager Task案だけが出ることを確認する。
  6. 音声ボタンから短く1往復し、字幕・音声・履歴保存を確認する。

成功：クラッシュせず、既存データを維持し、通常会話・外観・整理・音声の主要導線が通ります。

安全な復旧

Upload後に失敗したBuild番号は再利用しません。再Archiveが必要なら、こちらへ結果を伝えてください。次のBuild番号へ進めます。

  • 署名エラー：Bundle IDやTeamを変更せず、Xcodeのエラー全文を共有する。
  • 処理が長い：同じArchiveを再Uploadせず、App Store Connectの処理状態を待つ。
  • 実機不具合：アプリを削除しない。操作、表示された文言、再現手順だけを共有する。
  • Build 43が不合格でも、Build 42はTestFlight上に残り、ロールバックできます。
