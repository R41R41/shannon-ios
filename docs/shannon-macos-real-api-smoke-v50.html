Macでも、同じ会話と作業の続きを安全に開く

目的は、Shannon Deskを端末固有の資格で実Shannonへ接続し、iPhoneと共通の会話・作業が読めること、Macを閉じても同じ現在地へ戻れることを確認することです。

このガイドは、開発側から実接続確認を案内された時だけ使います。

接続URLは資格情報です。チャット、スクリーンショット、Git、メモへ貼り付けません。現在の安定版TestFlight Build 43は削除しません。

1. Macアプリを起動

  1. Xcodeで /Users/arairyo/Documents/Codex/2026-08-31/shannon-macos-m3/apps/macos-app/ShannonDesk.xcodeproj を開きます。
  2. Schemeを ShannonDesk、実行先を My Mac にしてRunします。Simulatorは使いません。
  3. 左下が「未接続」で、アプリが操作可能なことを確認します。

2. 開発側から一度だけ接続

  1. 開発側がAzureの信頼済み運用CLIから、30分・一度限りの接続リンクを1件だけ発行します。現在のiPhone版には、接続リンクを発行する設定画面はありません。
  2. 開発側がリンク本文を表示・保存せず、起動中のShannon Deskへ直接渡します。URL本文はチャット、スクリーンショット、Git、メモへ共有しません。
  3. Shannon Desk左下の接続行を開き、「接続を確認」を押します。

3. 読み取り中心の確認

  1. 「認証された通信」が「確認済み」になり、既存トークのタイトルが表示されることを確認します。
  2. 既存トークを1件開き、履歴が読めること、⌘Fでタイトル検索できることを確認します。
  3. 「作業全体」を開き、作業を1件選んで現在地インスペクタを開きます。元トークへの移動ができることを確認します。
  4. その状態でShannon Deskを終了・再起動し、同じ画面・トーク・選択作業・インスペクタ開閉が復元されることを確認します。

4. 書き込み確認（案内があった場合だけ）

  1. 新しいトークを作り、「Mac接続確認。短く返事をしてください」と1回だけ送ります。
  2. 返答後、iPhoneにも同じトークと返答が見えることを確認します。
  3. 不要ならトークのメニューからアーカイブします。履歴やアプリ自体は削除しません。

成功の見え方

  • 端末名「このMac」で認証済み通信になる
  • 既存会話と作業が読み込まれ、元会話へ往復できる
  • 終了後も選んでいた現在地へ復元される
  • 書き込み確認を行った場合、MacとiPhoneに同じトークが見える

今回の互換性境界

AI rolling summaryの「現在地」はMac側に実装済みですが、API変更を本番へ統合・配備するまでは既存トークに表示されません。表示されなくても、この段階の接続失敗とは判定しません。既存APIが返す会話・作業・見出しで確認を続けます。

失敗した時の安全な戻し方

  • 通信失敗: Macのネット接続を確認し、「接続を確認」をもう一度だけ押します。
  • 401／無効: 古いリンクを再利用せず、開発側が信頼済み運用CLIから新しい接続リンクを1件だけ発行します。
  • 履歴が空・内容が違う: 新規送信をせず終了し、iPhone側の履歴は削除しません。
  • Macだけ切り離す: 左下の接続詳細から「このMacの接続を解除」を選びます。iPhoneアプリとサーバー上の会話は残ります。
  • クラッシュ: 再送や再接続を繰り返さず、直前に押した項目だけを報告します。資格情報や実会話本文は報告へ含めません。
