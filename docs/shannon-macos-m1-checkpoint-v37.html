今回固めたこと

認証済み通信を確認

Keychainに値があるだけで「利用可能」とはしない。起動後とペアリング後に認証付きthread取得を行い、未確認・確認中・確認済み・失敗をSettingsへ表示する。

失効と一時障害を区別

HTTP 401なら失効した端末資格を削除する。通信断なら資格を保持し、再ペアリングせず再試行できる。

Mac固有コードを隔離

Macの画面、添付読込、保存パネル、作業表示、Macテストを apps/macos-app へ集約。共有CoreからAppKit依存を除いた。

Mac専用テスト入口

scripts/verify.sh mac がMac固有テスト5件とDebugアプリを検証する。mac-release で署名なしReleaseも確認できる。

配布の判断

製品の扱いMac版は別人格・別バックエンドではなく、iPhoneと同じShannonへ接続するネイティブクライアント。
App Store既存のShannon app recordへmacOS platformを追加し、同じbundle ID com.r41r41.shannon を使う方針。Xcode targetとplatform固有build番号は分ける。
資格情報MacはMac自身のKeychainへペアリング資格を保存する。iPhoneのtokenやOpenAI API keyをコピーしない。
現時点署名・notarization・App Store Connect登録・配信は未実施。外部システムは変更していない。
