01 / conclusion

先に作るのは、新画面ではなく「比較できる仕組み」

結論：ShannonにもAether／Voyagerと同じ、個人データ・本番接続・課金を使わないUI監査モードを入れる。その固定状態から同じ画面をLight／Dark・大きな文字で撮影し、Talk → Memory → Work／Settingsの順に3つの大きなUXバッチで直す。

03 / what to borrow

他の2アプリから、見た目ではなく原則を借りる

Aether

コンテンツの後ろにUIを沈める

ヘッダーとcomposerを薄くし、文章が画面の主役になる。Shannonでは会話本文を主役にし、上部切替・入力欄・作業状態を必要な時だけ浮かせる。Aetherの文書UIそのものは複製しない。

Voyager

固定fixtureと大きな文字で崩れを先に見る

起動引数で通常・空・失敗・大きな文字を安全に再現し、同じ条件で改善前後を撮る。Shannonの会話・記憶・タスクにもこの監査方法を移植する。

Apple HIG

iOS標準の読みやすさと操作性

Dynamic Typeで階層を保ち、横並びの補助情報は大きな文字で縦へ組み替える。主要操作は44ptを基準とし、safe areaと標準の戻る操作を尊重する。

Material 3

状態は色だけで示さない

選択・無効・処理中・失敗を色＋形＋文言で表す。Expressiveな形や動きはシャノンの感情に使い、常時すべてを動かさない。

会話に向き合う場所
顔を大きく、上半身は下へ自然に溶かす。短文は一息で、長文は「続きを読む」。待機／考え中／発話中を同じ舞台の変化として見せる。

Scroll mode

返信は全幅を維持。40pt前後の表情、名前、時刻だけをコンパクトに置き、感情名は必要な時だけ。コピーは見つけられ、本文選択も維持。

Dialogue mode

「縦長画像＋吹き出し」から、顔・声・字幕が一つの場にいる構図へ。Live2Dなしでも、crop、光、呼吸、状態遷移で存在感を作る。

Composer

一つの入力面を維持し、空なら音声、文字があれば送信。背後の会話は見えるが、入力中文字と境界は十分読める。入力中は画面遷移を起こさない。

05 / memory & settings

メモリーは人格、運用情報は設定へ

いま

一目で感じる

現在の表情、短い状態文、今日の関心、頭に浮かんでいる2件。数値メーターは折りたたみ詳細へ。

知識

探して直せる

カテゴリ、質問、回答を主役にし、根拠・確信度・更新日は詳細へ。手動編集は維持し、会話で直す入口も補助表示する。

記憶

活動の時間が見える

日記を横スクロールだけに閉じず、日付順の縦一覧へ。睡眠、調べ物、覚えたことを静かなタイムラインで読む。

設定

カードの羅列をグループへ

「シャノン」「外観とアイコン」「音声」「アプリと接続」の4区分。音声診断、コスト、自発性評価、配信履歴は通常利用から一段奥へ置く。

維持

既に良いものは作り直さない

トーク／メモリーのタップ切替、設定の独立画面、左端Drawer、タイトル編集、返信の表情固定、全幅本文、コピー、2モードのApp Icon設定はそのまま使う。

06 / deterministic audit

実装する監査シナリオ

領域固定状態必須表示見ること
Talk空・通常・長文・送信中・失敗・キーボードLight / Dark本文幅、metadata、最終行、入力欄、モード導線
Dialogue待機・考え中・短文・長文・入力中Light / Dark顔の占有率、吹き出し、視線、画像の下端、集中
Threads空・複数・選択・未読・タイトル編集Light / Dark最終時刻、新規作成、長いタイトル、操作の発見性
Memoryいま・知識・日記・空・読込失敗Light / Dark頭の中らしさ、編集、根拠、戻り、情報密度
Work提案・実行中・許可待ち・停止・完了・失敗Light / Dark次に押すもの、通常会話との競合、永続状態
Voice接続・聞く・考える・話す・失敗Light / Dark字幕、停止、割込み、状態の理解、再試行
Settings通常・アイコン・外観・更新・接続不調Light / Dark区分、画像preview、異常だけが目立つこと
AccessibilityAX3・Reduce Motion・VoiceOver順序代表8状態縦組み替え、切れ、44pt、色以外の状態表示
安全境界：専用UserDefaults、固定日時、合成会話、合成記憶、合成タスクを使う。Keychain、本番API、Azure SQLite、ユーザー会話、課金LLMを一切読まない。
