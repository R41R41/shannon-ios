## What changed

- Self interests use the canonical memory writer, immutable revisions and changes, durable real-night 2/2 quotas, bounded weights, current source/forgetting checks and individual CAS undo/pin/ban/forget/resume.
- Task trees extend the existing engine and approved Host commands. Completion needs original attempt/turn/action/lease and real test evidence; legacy tasks continue without invented proof. Durable learning callbacks read exact original action receipts through a scoped port.
- Feedback binds real tool-backed owner replies and verified task results to one original choice. Reaction revisions and operation read-back feed the versioned 80/20 serve fold with independent cursors. Unknown operations, audience changes, forgetting and rollback retain their boundaries.
- Self revision has durable ordered gates, work-level failure freeze, original authority/budget/stop, physical paths and information provenance, exact grants, actual bounded code/data checks and snapshots. Validation interrupted before dispatch is closed without retaining rights; dispatched uncertainty is retained.
- Transport responsibilities moved into perception, attention, inhibition and memory; constructors moved into wiring. Pure rule/frame ports bound worker reachability and import cycles. Actual layer violations went from 43 to 0 with unchanged rules and no exception.
- iPhone and Mac share new DTO/model behavior and approved diary/reaction/work-detail controls, preserving existing navigation, voice, memory, study and task controls. A DEBUG-only native fixture replaces the root with synthetic in-memory clients and performs no live network calls or writes to real domain records.

## Mac native launch smoke

After unlock, `scripts/smoke-macos-inspector-launch.sh` passed all seven real cases against the built Mac target, both in the unlocked rerun and the final rerun: development/task, development/outline, release/task, work/task, talk/task, talk/outline and talk/figure. Each case retained the 12-second observation, window count and AppKit constraint checks. This verifies native launch/restoration behavior; it does not establish complete Stage 5 visual/interaction or device acceptance.

The earlier locked run remains excluded. Its old `ioreg | grep -q` detector could miss the lock branch under `pipefail` because early grep completion produced SIGPIPE status 141. The corrected detector drains `ioreg`, checks startup and each case, monitors the survival loop and rechecks before window counting. An actual locked invocation returns 3 before app launch. Seven independent synthetic guard/cleanup cases also passed without child or temporary-directory leaks; these guard tests are separate from the real smoke result.
