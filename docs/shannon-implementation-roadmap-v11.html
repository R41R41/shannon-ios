v0.5 Aether Link · 読む／提案する境界が完成

読み取り ✓Aether設定で明示的にONにした場合だけ、最大24件の短い文脈を本人専用VMの橋へ同期。Shannonは通常3件、Aetherについて尋ねた時でも5件までしかFCAへ入れない。
漏らさない ✓送信対象はID・更新時刻・タイトル・480文字以内の平文化した抜粋・タグ・種類・状態。本文フィールドや未知の項目が混ざればサーバーが拒否する。
費用 ✓抽出・重複回避・関連性選択はすべてコード。連携そのものはLLMを呼ばず、Shannonの通常会話も従来どおり1回だけ。
提案 ✓Shannonの返答を長押しして明示的に送ると、所有者だけが読める保留箱へ届く。自動で提案を量産せず、本文の改行やMarkdownも保つ。
承認更新 ✓Aether設定で新規メモ保存・既存メモへの追記案・却下を選ぶ。追記は元の更新時刻を再確認し、差分画面で採用した時だけローカルSQLiteへ書く。
理由Aetherのメモ本体はiPhone内SQLiteにある。App Groupのネイティブ依存を先に増やすより、既存の本人専用VM認証を使う方が安全に段階導入できる。

v0.9 Evaluation · 本文を集めずに傾向を見る

対話品質明示知識の抽出・訂正・矛盾・否定・複数ターンなど28対話パターンを含む自動試験を継続する。実LLM試験は明示実行だけにし、通常の検証では費用を発生させない。
費用会話と睡眠を別レーンでtoken・推定費用として集計。睡眠側は月間ブレーカーを正本にし、外部観測の障害で停止規則を失わない。
沈黙判断自発ループごとに候補数・配信数・停止理由だけを最大90日保存。会話本文、記憶、URLは評価ログへ複製しない。
画面メモリーの「いまのシャノン」に、直近30日の話しかけた割合・候補数・静かにした回数を表示する。
Langfuse現時点では未接続。複数モデルやプロンプトの比較が必要になった時にCloudを任意導入し、匿名trace・model・token・時間・statusだけを送る。本文と記憶は既定で送らない。

v1.0 Daily Companion · 通知経路を実装

iPhone登録 ✓起動時に通知許可を確認し、APNsが返す端末トークンを本人のペアリング認証でサーバーへ送る。トークンは起動ごとに取得し直し、アプリ内へ永続キャッシュしない。
配信 ✓世界探索 → 黙る判断 → 会話保存の後、未読の自発メッセージだけをHTTP/2でAPNsへ送る。通知本文には該当トークIDと固定済み表情を含める。
開く ✓通知をタップすると該当トークへ移動し、そこで初めて既読化。単なる起動時取得では未読を消さず、トーク切替とホーム画面バッジを同期する。
壊れにくさ ✓一時障害は5分・30分・2時間の最大3回再試行。APNsが端末の失効を返した場合は登録を停止し、次回アプリ起動時の新トークンで復帰する。
秘密情報 ✓.p8はGit対象外。Key ID・Team ID・Bundle ID・鍵パスはVMの所有者専用環境ファイルにだけ置く。未設定時は通知だけ無効になり、探索・会話・未読箱は動き続ける。
実配信 ✓2026-09-04、Apple DeveloperでSandbox＋Production対応キーを発行しAzure VMへ配置。APNsはHTTP 200で受理し、物理iPhoneで通知表示・バッジ・通知タップ遷移を確認した。参考：端末登録 / APNs送信
自然運用 ✓同日7:00:57、テスト送信とは別に通常の世界探索ループが80件から1件を選択。会話保存とAPNs配信を1回で完了し、8:12にユーザーが開いて既読になった。
省負荷運用 ✓通知の再送確認は毎分のまま、自発判断だけを状況別に予約する。夜間は7時、配信済みなら翌7時、候補不足や会話直後なら15分後まで休み、空振りDB書き込みを抑える。SIGTERM時は待機と外部取得を即時中断し、安全に再起動する。
