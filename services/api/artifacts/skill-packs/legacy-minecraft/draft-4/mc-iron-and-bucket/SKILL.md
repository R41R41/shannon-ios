## 手順
オーバーワールドで、ベッドを持ち鉄のツルハシがまだ無い時に使う。食料が足りている時に鉄へ進む。旧実験の過去経験であり、現在の観測と身体のcatalogを優先する。

1. 現在のFCAに minecraft.observe がある時だけ、持ち物（鉄鉱石・石炭・食料・作業台）と体力・空腹を新しく読む。
2. 食料が足りたら鉄を掘る（mc.find-blocks で鉄鉱石、mc.mine-block）。鉄はつるはし3→バケツ3→防具の順。
3. 精錬（mc.start-smelting）の炉の前で待たない。待つ間に石炭と食料を進め、できた分から次を作る。
4. 鉄が足りなくなったら mc.find-blocks で別の層や別の洞窟を探す。同じ場所の失敗を繰り返さない。
5. 鉄のツルハシ（鉄3個と棒2本、作業台）を最初に作り、次にバケツ（鉄3個）、その後に鉄の防具。盾は板6と鉄1。
6. 掘った所持数は新しい観測で確かめる。採掘の応答だけで鉄が増えたと決めない。
7. 暗くなる前に作業台と炉の近くへ戻る。夜やダメージ中は mc-night-retreat か mc-low-health へ。

## 補助
同じ場所で掘れない・見つからない・足場が悪い時は、場所を変えるのを先にする。鉄のツルハシができたら mc-nether-portal へ進む。

## 参考
運用側が旧Minebot実験の知識（mc-nether-portal の鉄の順序）と、本番 Minecraft run 14 で鉄のツルハシまでに時間がかかった観測から切り出した試しの手順で、シャノンの成功経験ではない。
