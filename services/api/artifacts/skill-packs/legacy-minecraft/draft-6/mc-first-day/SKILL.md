## 手順
オーバーワールドで、石のツルハシがまだ無い時に使う（スポーン直後から）。旧実験の過去経験であり、現在の観測と身体のcatalogを優先する。

1. 現在のFCAに minecraft.observe がある時だけ、biome・時刻・持ち物・近くの木・動物・村の気配を新しく読む。
2. 最初の一手は mc.mine-block（blockName=近くの原木 例 oak_log、count=6）。周りに見えた羊・牛・村は覚えておく。
3. mc.craft-one で板材→作業台→棒→wooden_pickaxe（板3＋棒2）。作業台は手持ちなら自動で置かれる。
4. mc.mine-block（blockName=stone、count=16）で丸石を集め、stone_pickaxe と stone_axe を作る。
5. 丸石の使い道: ツルハシ3・斧3・剣2・かまど8。剣（stone_sword）も作っておくと羊や動物を早く倒せる。
6. 木材の要る量の目安: 原木1本で板4枚。作業台に板4、棒4本に板2、木のツルハシに板3、ベッドに板3、チェストに板8。原木は合わせて10本ほど集める。足りなくなってから取りに戻らない。
7. 石の道具ができたら mc-food-and-bed（夜の前に食料とベッド）へ進む。暗くなる1分前・敵が近い時は mc-night-retreat へ。
8. 掘った・作った数は新しい観測の所持数で確かめる。採掘や作成の応答だけで増えたと決めない。

## 補助
同じ木が掘れない・届かない時は別の木へ移る。周りを見て回るのは木を掘る道すがらにし、遠くへ探しに出ない。村が見えたら寄ってよい（mc-food-and-bed の村の手順）。作業台は持ち歩けるので、置いた場所に縛られない。

## 参考
運用側が旧Minebot実験の知識（seed-survey-surface-early、seed-village-in-sight、k-6703a43f）と、owner が示した序盤の順番（スポーン→周りを見る→木→木と石の道具→石の斧→木材の量）から書いた試しの手順で、シャノンの成功経験ではない。mc-early-toolchain の後継として、最初の一手を身体の道具の名前と引数で書いた。importは利用0・成功0から始まる。
