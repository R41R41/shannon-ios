## 手順
オーバーワールドで、鉄のツルハシを持ち、ネザー行きが目的にある時に使う。旧実験の過去経験であり、現在の観測と身体のcatalogを優先する。

1. 現在のFCAに minecraft.observe がある時だけ、所持品・体力・空腹度・周囲を新しく読む。観測が無ければ材料がそろったと推測しない。
2. 黒曜石は diamond_pickaxe でしか掘れない。無い間は、枠の型に溶岩を注ぎ、水で固めて枠を鋳造する。
3. 型は mc.place-block-at で丸石を並べる。溶岩は mc.use-item-on-block（lava_bucket）、固めは water_bucket。
4. 枠ができたら火打石で着火し、面の中央へ mc.enter-portal。黒曜石10個を持つなら mc.build-structure。
5. 鋳造は、溶岩源の隣に立って空のバケツで溶岩を汲み、型の穴へ注ぎ、水を注いで黒曜石にし、水を汲み戻す。これを枠の10か所ぶん繰り返す。足場と退路を先に確かめ、遠くからバケツを使わない。
6. 型にした丸石は、固まった後に掘って外す（黒曜石は掘らない）。diamond_pickaxe を持つなら、溶岩だまりに水を流して黒曜石にし、掘って10個集め、mc.build-structure（nether_portal）で建てる手もある。
7. 鉄は先に鉄のつるはし分（3個）、次に盾（板6＋鉄1）、次にバケツ（鉄3、作業台が要る）に回す。鋳造にはバケツが2つ要る。作業台が手元に無ければ先に作って置く。
8. 着火後は mc.find-blocks などでポータル面（nether_portal）ができたことを確かめ、火ではなく面の中央へ入る。
9. 入る前の目安: 鉄の防具、盾、鉄の剣、焼いた食料十数個、丸石を多め（2スタック程度）、ハーフブロック、予備のつるはし。足りない物は最小限だけ補う。

## 補助
catalogに無い操作名は使わず、不足を伝える。操作の受付を成功の証明にしない。結果は新しい観測で確かめる。入る前の準備の目安は旧知識で反証もあり、全部そろうまで待ち続ける理由にはしない。型の作り方や溶岩を置く位置は、現在の地形と観測に合わせて決める。
