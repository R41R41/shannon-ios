## 手順
オーバーワールドで、鉄のツルハシを持ち、ネザー行きが目的にある時に使う。旧実験の過去経験であり、現在の観測と身体のcatalogを優先する。

1. 現在のFCAに minecraft.observe がある時だけ、所持品・体力・空腹度・周囲を新しく読む。観測が無ければ材料がそろったと推測しない。
2. 水を汲み、溶岩源の隣まで寄る。足場と退路を確かめてから、溶岩の縁へ正面から水を流す。
3. 黒曜石になったら掘り、枠に要る数（10個目安）まで繰り返す。遠くからバケツを使わない。
4. mc.build-structure（nether_portal）で建て、火打石で着火。面ができたら中央へ mc.enter-portal。
5. 鉄は先に鉄のつるはし分（3個）、次に盾（板6＋鉄1）、次にバケツ（鉄3、作業台が要る）に回す。作業台が手元に無ければ先に作って置く。バケツが無いと溶岩だまりに進めない。
6. 着火後は mc.find-blocks などでポータル面（nether_portal）ができたことを確かめ、火ではなく面の中央へ入る。mc.build-structure は材料を確かめてから建てる。
7. 入る前の目安: 鉄の防具、盾、鉄の剣、焼いた食料十数個、丸石を多め（2スタック程度）、ハーフブロック、予備のつるはし。足りない物は最小限だけ補う。

## 補助
catalogに無い操作名は使わず、不足を伝える。操作の受付を成功の証明にしない。結果は新しい観測で確かめる。入る前の準備の目安は旧知識で反証もあり、全部そろうまで待ち続ける理由にはしない。
