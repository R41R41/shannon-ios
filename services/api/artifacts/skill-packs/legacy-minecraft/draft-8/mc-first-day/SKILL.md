## 手順
オーバーワールドで、石のツルハシがまだ無い時に使う（スポーン直後から）。旧実験の過去経験であり、現在の観測と身体のcatalogを優先する。番号の行は進め方、最後の「使う道具」は呼び方。

1. 現在のFCAに minecraft.observe がある時だけ、biome・時刻・持ち物・近くの木・動物・村の気配を新しく読む。
2. まず近くの原木を12〜16本まとめて掘る。6本では作業台・道具・ベッド・かまどの板材が足りず、途中で取りに戻ることになる。
3. 板材→作業台→棒→木のツルハシ（板3＋棒2）。作業台は手持ちなら自動で置かれる。置けない時は足元のすぐ横の地面へ置き直す。
4. 丸石を16個ほど掘り、石のツルハシと石の斧（各3個）、石の剣（2個）を作る。狩りと戦いの前に剣を手に持つ。残りはかまど8に回す。
5. 木材の目安: 原木1本で板4枚。作業台に板4、棒4本に板2、木のツルハシに板3、ベッドに板3、チェストに板8。足りなくなってから取りに戻らない。
6. 石の道具ができたら、夜の前に食料とベッド（mc-food-and-bed）へ進む。暗くなる1分前・敵が近い時は mc-night-retreat へ。
7. 掘った・作った数は新しい観測の所持数で確かめる。採掘や作成の応答だけで増えたと決めない。

使う道具（名前と引数。身体の catalog が正）:
- 原木・丸石: mc.mine-block（blockName=oak_log など近くの原木を1種類だけ。「,」で並べない。count=12 や 16。丸石は stone）
- 板材・作業台・棒・道具: mc.craft-one（itemName=oak_planks、crafting_table、stick、wooden_pickaxe、stone_pickaxe、stone_axe、stone_sword）。作業台を置き直す: mc.place-block-at
- 剣を持つ: mc.equip-item（itemName=stone_sword、destination=hand）

## 補助
同じ木が掘れない・届かない時は別の木へ移る。周りを見て回るのは木を掘る道すがらにし、遠くへ探しに出ない。村が見えたら寄ってよい（mc-food-and-bed の村の手順）。作業台は持ち歩ける。
