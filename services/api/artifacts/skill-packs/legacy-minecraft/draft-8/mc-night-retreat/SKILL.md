## 手順
オーバーワールドの夕暮れ・夜、または敵が近く退避が必要な時に使う。旧実験の過去経験であり、現在の観測と身体のcatalogを優先する。番号の行は進め方、最後の「使う道具」は呼び方。

1. 現在のFCAに minecraft.observe がある時だけ、体力・空腹・酸素・水中か・敵・周囲の足場を新しく読む。観測が届かなければ安全になったと推測しない。
2. ベッドがあり敵が8マスより遠ければ、暗くなってすぐ寝て夜を飛ばす。朝はベッドを拾って持ち歩く。
3. ベッドが無ければ地上をさまよわず、すぐ縦穴を掘って入り頭上を塞ぐ。中で肉を焼き、精錬とクラフトを進める。
4. 夜は高さ16より下へ降りない。防具・焼いた食料・ベッドがそろうまで、深い洞窟やダイヤ掘りは明るくなってからにする。
5. 足元が空洞で縦穴が掘れない時は、その場に丸石の囲いを建てる（丸石10個とハーフブロック4個。丸石3個でハーフブロック6個）。
6. 体力が半分以下なら mc-low-health。食料が無い夜は穴の中で精錬やクラフトを進め、明るくなったらすぐ食料（mc-food-and-bed）。
7. 敵から逃げる時は水辺へ逃げない。乾いた近場の足場と遮蔽を確かめる。塞いだ中で敵が近い間は掘って出ない。出る前に時刻と敵を確かめる。

使う道具（名前と引数。身体の catalog が正）:
- 寝る: mc.sleep-in-bed
- 縦穴: mc.dig-shelter。昼に地下へ: mc.stair-mine（targetY）
- 水から出る: mc.leave-water。囲い: mc.build-around-self（structureName=slit_shelter）。ハーフブロック: mc.craft-one（itemName=cobblestone_slab）
- 敵を確かめる: mc.list-nearby-entities

## 補助
unknownの身体操作は元の結果を待つ。遮蔽の受付を生存の証明にしない。旧実験の退避には失敗や被ダメージもあり、死亡回避の保証はない。夜の前にベッドと食料をそろえておけば、この手順はほとんど要らない（mc-food-and-bed）。
