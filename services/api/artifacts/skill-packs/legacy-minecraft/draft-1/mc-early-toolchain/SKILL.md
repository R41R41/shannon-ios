## 手順

オーバーワールド序盤の安全な昼間に使う。旧実験の条件は地上、体力18以上、空腹度14以上、敵の接近なし。これらは成功保証や固定の安全基準ではなく、現在の状況に合うかを確かめる目安。

1. 現在のFCAに minecraft.observe が提供されている時だけ、持ち物、体力、空腹、敵、足場を新しく確認する。未参加・切断・観測不足なら実行できる状態を先に確認する。古い実験の場所、設備、資源は現在のワールドの事実にしない。
2. 現在提示された身体の道具と引数schemaを確認する。native名 mine-block は blockName と必要数、craft-one は itemName と必要数を受け取る。表示されていなければ名前から呼び出しを捏造せず、使える道具の不足を伝える。
3. 原木、板材、棒、作業台、採掘道具の所持数を確認し、欠けた直近の材料だけを集める。木製ツルハシに必要な板材3個・棒2本と作業台を先に確保する。作成済みの材料を別用途へ使い切らない。
4. 木製ツルハシが使えるなら、乾いた足場と短い退路がある石を必要量採掘する。採掘の応答だけで所持を決めず、丸石が増えた新しい観測を確認して石製道具へ進む。
5. 道具ができたら、当面の食料、燃料、退避用ブロックを確認して次の依存工程へ進む。空腹低下や食料不足がある時は、この順序を無条件に優先しない。各工程の現在の所持・実行結果を目的の進捗として報告する。

## 補助

失敗の原因が材料、設備、道具の破損、足場、敵のどれかを新しい観測で確認する。unknownや切断で元操作の結果が不明なら、同じ操作や新しいIDでの再送をせず元の結果を待つ。所持増加が確認できない採掘を完了扱いにしない。
