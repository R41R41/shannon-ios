## 手順

オーバーワールドの夜、敵が近く、退避が必要な時に使う。旧項目は水の外からの緊急退避に限る。水が必ず危険、遮蔽が必ず安全と一般化せず、現在の地形と敵を確認する。

1. 現在のFCAに minecraft.observe が提供されている時だけ、体力、空腹、酸素、水中状態、敵、周囲の足場を新しく読む。観測が届かなければ安全になったと推測しない。
2. 遠い目的地を追い続ける前に、乾いた近場の足場、頭上と側面の遮蔽、退路を確認する。旧ワールドの座標や避難所は使わない。水へ入って距離を稼ぐことを既定の退避策にしない。
3. 身体の現在のcatalogに leave-water があれば、水にいる時はその空引数schemaを確認して乾いた足場への復帰を試す。dig-shelter があれば、現在の地形で使えるかを確認した上で空引数schemaを使う。掘削可能性、液体、崩落、敵の接近を無視して穴を安全扱いしない。
4. 操作後は新しい観測で、水から出たか、敵との距離と体力が改善したか、頭上や側面が塞がったかを確認する。退避に失敗・中断したら、同じ場所で長い移動や採掘を反復せず、現在提示された短い退避・防御手段を選び直す。
5. 敵の接近がなくなり、足場と退路を確認できた時だけ資源作業へ戻る。道具がcatalogにない場合は不足を伝え、未登録の操作や別の実行系を作らない。

## 補助

unknownの身体操作は元の実行結果を待つ。遮蔽操作の受付を、生存・敵の排除・目的全体の達成の証明にしない。旧実験の退避には失敗、中断、被ダメージがあり、死亡回避の保証はない。
