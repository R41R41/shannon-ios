## 手順

オーバーワールドで原鉄などの材料、燃料、安全な設備がある時に使う。旧項目の目安は体力14以上、空腹度10以上、敵の接近なし。長い待機を安全に行える保証にはしない。

1. 現在のFCAに minecraft.observe が提供されている時だけ、体力、空腹、敵、持ち物、かまどの存在を確認する。かまどの場所は新しい観測で得たものだけを使い、旧実験の座標を移さない。
2. 現在の身体catalogに start-smelting と withdraw-from-furnace があるか確認する。開始のschemaは x/y/z、inputItem、fuelItem、必要数、回収のschemaは x/y/z、slot、waitForCompletion。現在提示された定義が異なる、道具がない、対象を観測できない時は呼び出しを捏造しない。
3. 当面の必要量と、クラフト等に残す材料を確認して精錬を開始する。開始結果を完成品取得と混同しない。拒否・材料不足・燃料不足・距離不足なら、結果と現在の観測から原因を解消する。
4. 現在の回収schemaで待たずに出力を確認できるなら、slotをoutput、waitForCompletionをfalseにして完成分だけを確認する。未完成の材料や燃料を不用意に取り出さない。待ち時間が返ったら、同じ回収を短い間隔で反復せず、退路を保てる準備または安全な待機を選ぶ。同じ身体で未確認の操作を重ねない。
5. 回収後は新しい持ち物観測でインゴット等の増加を確認し、必要な道具や装備へ進む。開始・待機・回収・目的達成をそれぞれ分けて報告する。

## 補助

旧ログの waiting_external は当時の非同期・受付表現の制約を含む。現在の回収機能が同じ回数失敗することや、一般的な戦術の成功率を意味しない。unknown、切断、結果待ちは元の操作を確認し、新しいIDの再送をしない。
