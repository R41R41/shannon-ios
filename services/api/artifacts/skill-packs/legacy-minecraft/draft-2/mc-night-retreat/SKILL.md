name: mc-night-retreat
description: マイクラの夜や敵の接近時、待たずに地下作業か近場へ退避する
---

## 手順
オーバーワールドの夕暮れ・夜、または敵が近く退避が必要な時に使う。旧実験の過去経験であり、現在の観測と身体のcatalogを優先する。

1. 現在のFCAに minecraft.observe がある時だけ、体力・空腹・酸素・水中か・敵・周囲の足場を新しく読む。観測が届かなければ安全になったと推測しない。
2. 夜の地上をさまよわない。地下へ入り、採掘・精錬・クラフトなど地下でできる用事を進める。地上でしかできない用事（食料・木）は朝に回す。
3. 朝まで待つのは、体力が半分以下・食べる物が無い・つるはしが無い時だけにする。待つと夜1回で数分が進まない。
4. ベッドを持っていて敵が近くにいなければ、暗くなってから mc.sleep-in-bed で夜を飛ばし、朝に回収して持ち歩く。羊が近い昼のうちに羊毛3個でベッドを作っておく。
5. 敵から逃げる時は水辺へ逃げない。乾いた近場の足場と遮蔽を確かめる。水の中なら mc.leave-water、穴が使えるなら mc.dig-shelter を、地形を確かめてから使う。
6. 塞いだ中で敵が近い間は掘って出ない。出る前に時刻と敵（mc.list-nearby-entities）を確かめる。

## 補助
unknownの身体操作は元の結果を待つ。遮蔽の受付を生存の証明にしない。旧実験の退避には失敗や被ダメージもあり、死亡回避の保証はない。
