## 手順
ネザー（the_nether）にいる時に使う。旧実験の過去経験であり、現在の観測と身体のcatalogを優先する。

1. 現在のFCAに minecraft.observe がある時だけ、体力・周囲の溶岩・足場・敵を新しく読む。
2. ガストの視線が通る開けた所や、溶岩の上の細い足場に長く立たない。遠くへ行く時は、ネザーラックを掘り進むか、丸石で壁と屋根を付けてから進む。撃たれたら、まず丸石か地形で視線を切る。
3. 長い移動は短い区間に分ける。経路の失敗や被弾が続いたら、同じ移動を繰り返さず、先に通路と退避場所を作る。
4. 敵が見えないのに体力が減る時は、火・溶岩・落下を疑い、その場で待たない。溶岩側をブロックで塞ぎ、足元と周りを固めて離れる。
5. 道具と防具の耐久を見る。壊れかけたら探索を止め、予備に替える。
6. 要塞を探す時は mc.find-structure（structureType=fortress）と mc.recall-places を使う。見つからなければ、無理に長距離を走らず別の方角を短く試す。

## 補助
ネザーでは水を置けない。開けた所での戦闘は避け、危ない時は体力の手順（mc-low-health）へ移る。操作の受付を安全の証明にしない。
