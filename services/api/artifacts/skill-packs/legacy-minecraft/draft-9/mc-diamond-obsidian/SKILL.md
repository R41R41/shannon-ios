## 手順
オーバーワールドで、鉄のツルハシ・バケツ・鉄の全身の防具があり、ネザーへまだ行っていない時に使う。旧実験の過去経験であり、現在の観測と身体のcatalogを優先する。番号の行は進め方、最後の「使う道具」は呼び方。

1. 現在のFCAに minecraft.observe がある時だけ、持ち物（ダイヤ・黒曜石・バケツ・火打石）・体力・食料・高さを新しく読む。
2. 鉄の全身の防具を着て、焼いた食料とベッドを持ち、昼のうちに mc.stair-mine（targetY=-54）で深い層へ降りる。夜は浅い所で精錬と料理。
3. ダイヤは深い層で鉄のツルハシで掘る。3個でダイヤのツルハシ。黒曜石はダイヤのツルハシでしか掘れず、ゲートには最小10個要る。
4. 黒曜石は溶岩源（流れていない溶岩）に水をかけて作る。流れる溶岩は丸石になる。水はバケツで汲み戻す。
5. 深い層では溶岩の上を掘らない。足元と前を確かめ、溶岩が見えたら丸石で塞ぐ。
6. ゲートは4×5の枠（角は要らない）。火打ち金（鉄1＋火打石。火打石は砂利から）で火をつけ、面の中へ入る。
7. 入る前の目安: 焼いた食料十数個、丸石64以上、ハーフブロック、鉄の防具と盾、予備のツルハシ。弓矢などは mc-travel-kit。全部そろうまで待ち続けない。
8. ネザーの1マスはオーバーワールドの8マス。帰りのゲートの場所は覚えておく。

使う道具（名前と引数。身体の catalog が正）:
- 深い層へ: mc.stair-mine（targetY=-54）
- 掘る: mc.mine-block（blockName=diamond_ore、count=3）、黒曜石は（blockName=obsidian、count=10）
- 溶岩源: mc.find-blocks（blockName=lava）。水をかける: mc.use-item-on-block（溶岩の座標、itemName=water_bucket）
- 作る: mc.craft-one（itemName=diamond_pickaxe、flint_and_steel）
- ゲート: mc.build-structure（structureName=nether_portal、置く座標）。入る: mc.enter-portal（面の座標）。場所: mc.recall-places

## 補助
黒曜石を鉄のツルハシで掘ろうとしない（何も落ちない）。所持が増えたかは新しい観測の所持数で確かめる。同じ溶岩だまりで失敗が続いたら別の溶岩源を探す。夜に深い所へ降りようとすると、防具・焼いた食料・ベッドが無い間は体が断る。洞窟でクリーパーを見たら戦わずに離れる（逃げ道が無ければ tower-up で3段上る）。ツルハシの耐久が尽きる前に予備へ持ち替える。

## 参考
運用側が旧Minebot実験の知識（mc-nether-portal の原典 k-d2d520e2、k-1be5104b、seed-nether-prepare など）と、身体の catalog の説明（use-item-on-block は水入りバケツで溶岩を黒曜石にする、build-structure の nether_portal は黒曜石10個）から書いた試しの手順で、シャノンの成功経験ではない。mc-nether-portal（鉄のツルハシで黒曜石まで進む誤り）の後継。draft-8 は実走16（防具0・焼いた食料0・ベッド無しで夜に高さ-7の洞窟へ降り、ゾンビに倒された）と owner の指示（全身の防具を作ってから）を受けて、降りる前の備えと昼に降りることを先頭に置き、最初の一手に道具の呼び方を添えた版。draft-9 は実走17（深い層でツルハシの耐久切れが5回、クリーパーと戦って爆死）を受けて、予備のツルハシとクリーパーを補助に足した版。importは利用0・成功0から始まる。
