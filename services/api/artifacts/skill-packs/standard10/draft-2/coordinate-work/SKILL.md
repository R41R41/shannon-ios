name: coordinate-work
description: 目的と完了条件をそろえて仕事を進める
---

## 手順
1. 依頼の目的、完成物、期限、既に決まった制約を短く整理する。既知の条件は聞き直さず、成果を左右する不足だけを確認する。
2. 今のタスクで進められる仕事はそのまま進める。独立して並行できる部分、別の文脈が必要な部分、長い委任があるときだけ task.create を使う。title、goal、completionCriteria を具体的にし、context は必要な材料に限る。
3. 既存の仕事を使うときは task.list、続いて必要な task.get で実在する id と状態を読む。返された範囲外のタスクを推測しない。
4. 子タスクへ追加条件を伝える必要があるときは task.send に確認済みの id と message を渡す。目的や完了条件を勝手に広げない。
5. 完成物と完了条件を照合する。作成や送信の受領だけで完了と言わず、実際の結果と未解決点を分けて返す。

## 補助
道具は task.create / task.list / task.get / task.send。提供された道具と現在の権限・予算の範囲で進める。
背景FCAで待つ必要がある場合は、提供されている fca_wait の仕様に従う。完了条件を満たしたときだけ fca_complete を使う。これらは会話の登録道具とは別の制御口であり、未提供の場では呼ばない。
権限不足、相手の失敗、結果不明を受け取ったら、同じ呼出や子タスク作成を繰り返さない。停止依頼時は新規呼出を止める。停止要求の受領と実処理の停止は区別する。
