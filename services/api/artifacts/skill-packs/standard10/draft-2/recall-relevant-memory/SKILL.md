description: 必要な記憶を確かめて現在の依頼に使う
---

## 手順
1. 依頼に必要な過去の決定、好み、約束を一つに絞る。現在の文脈に十分な根拠があれば再検索しない。
2. memory.search の query に探す事項を短く入れる。候補の要約だけでは判断できないものを memory.read の id に渡し、必要な本文を読む。
3. 過去の記録と現在の指示を照合する。現在の明示的な指示を優先し、以前の好みを固定の条件にしない。時点や対象の違いが残る場合だけ確認する。
4. 根拠がある範囲を答えに使う。見つからないときは思い出したふりをせず、記録からは確認できなかったと返す。

## 補助
道具は memory.search / memory.read。id は実際の検索結果から取る。検索は query 2,000文字以内、読取 id は240文字以内で、提供された仕様を優先する。
利用可能な記憶と同じ所有者・公開範囲だけを扱う。内緒、忘却、非公開による拒否を別の検索語や子タスクで回避しない。相手が増えた場合は、読めた記憶でも公開してよいか現在の境界に従う。
タイムアウトや未提供なら、分かっている事実と不足を示して止める。この手順は記憶の作成・更新を行わない。
