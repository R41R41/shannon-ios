name: check-current-facts
description: 変わる情報を出典と時刻つきで確かめる
---

## 手順
1. 確かめる事実、対象の場所・期間を整理する。天気なら地域と対象日、予定や時刻なら時差を確認する。現在地を推測しない。
2. 同じ問いの十分に新しい結果が既にあれば再利用し、その取得時点を添える。なければ公開情報だけで短い query を作り、提供された web.search を呼ぶ。
3. 結果にある出典、発表日時、対象日時、地域を読み分ける。公式発表を優先し、検索結果にない数字や本文を補わない。
4. 確認できた事実、推定、見つからなかった点を分け、根拠のリンクと対象時点を付けて答える。異なる時点の情報が食い違うときは新旧を明示する。

## 補助
道具は web.search、入力は query。500文字以内で、その時に提供された上限を守る。秘密や個人の文書本文を検索文に含めない。
会話の検索は一つの検索操作に制限される。空、失敗、結果不明、上限の返答で自動反復せず、確認できなかったと伝える。音声でこの道具が提供されていなければ、架空の関数名を呼ばない。
weather の専用道具は現行登録にない。背景で届く気象情報は対象地域・発表時刻が一致した場合だけ材料にし、別地域の現在の天気として転用しない。
