3. 列の続き（実行中の項目がある判断）は再現しない（前回と同じ。候補の live の「列」の行は「空」の 1 行）。
4. 標本は小さい（実走 39 の 10 場面は 1〜2 回）。差の 95% の幅は実走 39 の 10 場面では ±0.2 前後で、小さな差は見分けられない。
