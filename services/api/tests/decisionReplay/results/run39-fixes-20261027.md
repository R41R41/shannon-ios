## 6. 本番に入れてよいかの見立て

- **分かったこと**
  1. 1 判断の入力と出力では、新しい手と実走 39 の直しは**悪くなっていない**（H−P は全部の集合で正または 0、悪くなった集合は無い）。dragon26 の 30 場面で +0.150、実走 39 の 10 場面で +0.500（95% の幅はどちらも 0 より上）。
  2. Sonnet は新しい手を**よく使う**（mc.act の 67%、実走 39 の場面で 90%）。主は go（48%）と mine（18%）。引数は契約の範囲に収まり、許す物（canDig・canPlace）は石・土系だけ、守りに止められた go・mine は 0。新しい手そのものの引数の誤りは 1/40。

- **仮説**
  - 差の大部分は、採点者が「go・mine・obsidian は体が契約どおり動く」と仮定して高く付けた分。採点者の×は 29 → 11 に減り、機械の検査の×は 6 のまま変わらない。体が契約どおり動かなければ（道が引けない・詰まる・not_loaded）、この差は小さくなる。
  - go が柱・地下への下り・黒曜石の足場まで含むので、柱の場面（体の pillarUp の不具合）で +0.625 になったのは、体の側の go が直した部品を使う前提のため。
  - 4 つの「知らない手」（`chest`・`furnace`）の増えは、短い書き方の例（`go …`・`mine …`）を見た model が、既存の手にも「名前 + 引数」の書き方を当てたため、かもしれない（P では 1/62、H では 4/62）。
